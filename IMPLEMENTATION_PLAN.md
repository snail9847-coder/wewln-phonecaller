# IMPLEMENTATION_PLAN — wewln-phonecaller

Поэтапный чек-лист разработки. Пункт отмечается `[x]` только при наличии доказательства
(коммит, вывод тестов, лог проверки). Неподтверждённые сведения помечены **[не проверено]**,
мои предложения по умолчанию — **[предложение]**.

- **Статус:** Phase 1 (аудит) завершена 2026-11-03. Phase 2 не начата — ждёт явного разрешения владельца.
- **Режим по умолчанию:** только симуляция. Реальные звонки, покупки и платные сервисы — только с явного разрешения.
- **Референс:** `risingpower/claude-phone@28efe1d` (MIT) — то же содержимое, что в загруженном `claude-phone-main.zip`.

## 1. Цель

Система исходящих AI-звонков, которой управляют из Notion и которая запускается на Windows 10/11:
кампании и контакты в Notion → backend (оркестратор и проверки безопасности) → адаптер телефонии
(mock или реальный провайдер) → голосовой AI-движок (STT → LLM → TTS) → статусы, транскрипты и итоги
обратно в Notion. Направления — международные, включая Азербайджан (+994), в пределах покрытия
провайдера и требований закона.

### 2.2 Что это за проект

claude-phone — локальная мини-АТС на одном Mac. Asterisk 22 (собирается из исходников) соединяет
**собственный настольный SIP-телефон владельца** (Yealink T31P или Linphone в той же локальной сети)
с сессиями Claude Code в iTerm2. Claude звонит владельцу через MCP-инструменты `call_<owner>` и
`notify_<owner>`, владелец звонит сессиям по внутренним номерам 301–399; есть голосовая почта,
оператор «0», игра Crack the Safe и управление лампами Govee. README прямо пишет: «Mac only (Apple Silicon)».

- Пакет `claude_phone/`: 22 файла, около 3 590 строк Python; 8 шаблонов Asterisk; 3 документа;
  8 файлов тестов (около 600 строк, 51 тест). Лицензия MIT © 2026 risingpower.
- Зависимости (`pyproject.toml`): Python ≥ 3.12; `aiohttp>=3.9`, `mcp>=2.3,<3`,
  `pyobjc-framework-EventKit>=10`; dev: `pytest>=8`.
- Внешние компоненты: Asterisk 22.11 (`scripts/build-asterisk.sh` с патчами под macOS и Homebrew),
  whisper.cpp `whisper-server`, macOS `say` и `afconvert`; опционально ElevenLabs, ntfy.sh, Govee LAN API.
- Issues/PR upstream: 1 открытый issue (совместимость с Yealink T26P), открытый PR #1 (голоса Siri),
  закрытый без слияния PR #3 «Run on Windows (WSL 2) and with analog phones» (643+/88−, 18 файлов, 2026-10-23).
  PR #3 не входит в zip и не прошёл ревью.

### 2.4 Несовместимые допущения

#### A. Звонит только собственному SIP-телефону (выхода в телефонную сеть нет)

- `claude_phone/daemon.py:591` — единственный исходящий вызов: `POST /channels` с
  `endpoint=f"PJSIP/{ring_ext}"`, то есть внутренний номер 200 или 201.
- `asterisk/pjsip.conf.tmpl` — только LAN-эндпоинты 200/201 и ACL `deny=0.0.0.0/0` +
  `permit=@@LAN_CIDR@@`; нет SIP-транка, регистрации у оператора и outbound proxy.
- `asterisk/extensions.conf.tmpl` — единственный контекст `from-desk`, всё уходит в Stasis.
- Нет E.164, проверки номеров и настоящего caller ID (вместо него подпись `repo/branch`).

#### B. Привязка к macOS

| Где | Что | Чем заменить в wewln-phonecaller |
| --- | --- | --- |
| `inject.py` | AppleScript (`osascript`) → iTerm2 | не нужно, вне задачи |
| `tts.py:25`, `tts.py:36` | `afconvert`, `say` | кроссплатформенный TTS-адаптер и ресемплинг в Python |
| `keychain.py` | `security` (Keychain) | переменные окружения и `.env`; опционально Windows Credential Manager через `keyring` |
| `cli.py:112–235` | launchd/`launchctl`, `~/Library/LaunchAgents`, пути `/opt/homebrew` | `python -m wewln_phonecaller serve`, PowerShell-скрипты |
| `config.py:127–141` | `route -n get default`, `ipconfig getifaddr`, `ifconfig` | не нужно (нет телефона в LAN) |
| `diary.py`, `pyproject.toml` | EventKit через PyObjC | не нужно; блокирует установку вне macOS |
| `scripts/build-asterisk.sh`, `docs/build-notes.md` | сборка под `aarch64-apple-darwin`, openssl из Homebrew | если понадобится Asterisk — Docker или WSL 2 |
| `config.py:19` | `ASTERISK_RUN=/tmp/cphone` (лимит длины unix-сокета macOS) | не нужно |

#### C. Остальные расхождения с требованиями

- Одна линия: `daemon.py:93` — `self.line = asyncio.Lock()` («one call with the owner at a time»).
  Нет кампаний, очередей, конкурентности, расписаний и повторов.
- Только английский: `whisper-server ... -l en` (`cli.py:113`), фильтр «шумовых» фраз STT на английском,
  британские голоса.
- Нет Notion, контактов, согласий, DNC/suppression, часов звонков, лимитов частоты, kill switch,
  разделения симуляции и продакшна.
- HTTP API демона (`127.0.0.1:8765`: `/call`, `/notify`, `/transfer` …) без аутентификации —
  защищён только тем, что слушает localhost.
- Логи — обычный текст (`log.py`) с транскриптами; нет структурированных логов и correlation ID.
  Записи и кэш речи удаляются через 30 дней (`housekeeping.py`), журнал инъекций в БД не чистится.
- Аудио рассчитано на LAN (G.722, 16 кГц); в телефонной сети обычно G.711 8 кГц (μ-law/A-law).
  Модуль `audioop` удалён из Python 3.13, поэтому конвертацию надо делать без него.
- Asterisk нативно на Windows не работает — только через WSL 2 или Docker
  **[общеизвестно, в этом проекте не проверялось]**.

### 2.6 Вывод

claude-phone **не подходит как основа** wewln-phonecaller: главного (звонков на внешние номера,
Notion, кампаний, мер безопасности, Windows) в нём нет, а зависимость от macOS не даёт даже установить
пакет на другой ОС. Переиспользовать можно примерно 10–15 % кода: ARI-клиент, паттерны STT/TTS и подход к тестам.

**Решение D1:** новый приватный репозиторий `wewln-phonecaller`; claude-phone остаётся внешним
референсом на `28efe1d`. Код переносится выборочно, в той фазе, где он нужен, с указанием источника
и текстом лицензии MIT в `THIRD_PARTY_NOTICES.md`. Форк не делаем: форк публичного репозитория
будет публичным и принесёт много нерелевантного кода.

## 3. Целевая архитектура (черновик, детали — в ARCHITECTURE.md на Phase 2)

```text
Notion: Campaigns · Contacts · Calls · Suppression · Control
   │  официальный Notion API (polling, токен из env)
   ▼
notion/ ──► orchestrator/ ──► safety/ (режим, kill switch, согласие, DNC, часы, лимиты)
                 │
                 ▼
           telephony/ (интерфейс) ──► MockProvider | реальный провайдер (Phase 4)
                 │  аудио и события звонка
                 ▼
           voice/: STT ⇄ LLM ⇄ TTS, состояние диалога, транскрипт, итог

storage/: SQLite — кампании, попытки, события, idempotency, audit, транскрипты
api/: aiohttp — /health, /ready, кампании, звонки, вебхуки, админ   ·   cli/: wewln …
```

- **notion/** — REST-адаптер на aiohttp с закреплённой версией `Notion-Version`; синхронизация кампаний
  и контактов; запись статусов, итогов и ошибок; обработка 401/403/404/409/429/5xx, бэкофф по `Retry-After`.
- **api/** — health/ready, кампании, звонки, вебхуки провайдеров, админ-действия (kill switch, arm/disarm)
  по токену; по умолчанию слушает только `127.0.0.1`.
- **core/** — модели pydantic: Contact, Campaign, CallAttempt, ConsentRecord, SuppressionEntry; явные машины состояний.
- **storage/** — SQLite (WAL) и миграции: campaigns, contacts, call_attempts, call_events,
  idempotency_keys, suppression, consent, audit_log, transcripts (с ретеншном).
- **telephony/** — протокол `TelephonyProvider`: `place_call`, `cancel_call`, `get_status`,
  `verify_webhook`, `parse_event`. `MockProvider` со сценариями: ответил, занято, не ответил, ошибка,
  автоответчик, обрыв посреди разговора.
- **voice/** — интерфейсы `STT`, `LLM`, `TTS` (и опционально speech-to-speech) и `ConversationEngine`:
  GREETING → DISCLOSURE → PURPOSE → DIALOG (LISTENING ⇄ THINKING ⇄ SPEAKING) → CLOSING → ENDED,
  ветки OPT_OUT и ERROR; barge-in, таймауты, транскрипт, структурированный итог.
- **orchestrator/** — планировщик, допуск каждого звонка, конкурентность (общая и на кампанию),
  rate limit, повторы с бэкоффом, идемпотентность.
- **safety/** — гейт режимов и kill switch; проверяется непосредственно перед каждым набором.
- **cli/** — `wewln serve | check-config | doctor | simulate | notion bootstrap | arm | disarm | kill-switch | purge`.

## 5. Модель безопасности звонков

- `simulation` по умолчанию: фабрика провайдеров отдаёт только `MockProvider`.
- Реальный звонок возможен, только если выполнены все условия:
  1. `WEWLN_MODE=production`;
  2. `WEWLN_PRODUCTION_CONFIRM` совпадает с точной фразой подтверждения;
  3. у кампании в Notion отмечено «Реальные звонки разрешены»;
  4. оператор выполнил `wewln arm --campaign <id> --ttl 30m` (запись со сроком действия в audit log);
  5. kill switch выключен.
- Kill switch (env, файл, API или Notion) сразу блокирует новые наборы; активные звонки завершаются штатно.
- Перед каждым набором: валидный E.164; страна в allowlist (+994 включается явно); номера нет в
  suppression/DNC; есть согласие или иное законное основание, если этого требует политика кампании;
  время в окне звонков по часовому поясу получателя (по умолчанию 10:00–19:00 **[предложение]**);
  соблюдены лимиты частоты на контакт; caller ID из утверждённого списка; соблюдены лимиты конкурентности и скорости.
- Защита от случайных дублей: кампания запускается один раз (идемпотентный старт), отпечаток
  «контакты + цель + окно» проверяется на совпадение с уже запущенными кампаниями.
- В начале разговора AI честно говорит, что это автоматический звонок с ИИ, от чьего имени и зачем.
  На «не звоните мне» или «стоп» (ru/az/en) — вежливое завершение и автодобавление в suppression.
- Запись разговора выключена по умолчанию; если включена — объявление о записи до начала разговора.
- Ретеншн транскриптов и контактных данных настраивается (по умолчанию 30 дней **[предложение]**),
  удаление командой `purge`; номера в логах маскируются.
- Никаких функций для обхода антиспама, подмены caller ID, обхода согласия или ограничений провайдера.

## 6. Черновик схемы Notion (уточняется на Phase 3)

- **Campaigns:** Name, Status (Draft/Scheduled/Running/Paused/Stopped/Completed), Mode (Simulation/Production),
  Real calls approved, Purpose, Script/Instructions, Language, Caller ID, Calling window, Allowed countries,
  Max attempts, Retry delay, Max concurrent calls, Recording, Start/End, Contacts, Calls.
- **Contacts:** Name, Phone (как введён), Phone E.164 (заполняет backend), Country, Time zone,
  Consent status, Consent source/date, Do not call, Campaigns, Last called, Attempts.
- **Calls:** Title, Campaign, Contact, Simulated, Status (Queued/Dialing/Ringing/In progress/Completed/
  No answer/Busy/Failed/Canceled/Blocked), Outcome, Started/Ended, Duration, Attempt, Provider call ID,
  Error, Summary, Transcript (с учётом ретеншна), Opt-out requested.
- **Suppression:** Phone E.164, Reason (Opt-out/DNC/Manual/Complaint), Source, Added at.
- **Control:** Kill switch и отображение текущего режима (решение всё равно принимает backend).

Интеграции Notion нужно выдать доступ к этим базам, токен хранится только в `NOTION_TOKEN`.
Лимит Notion API — в среднем около 3 запросов в секунду на интеграцию **[проверить на Phase 3]**;
в новых версиях API базы данных разделены на data sources — версию выбрать на Phase 3 **[проверить]**.

## 7. Телефония: предварительные данные (перепроверить на Phase 4)

- Бесплатного выхода в телефонную сеть нет: звонки на реальные номера +994 будут платными у любого провайдера.
- Предварительные цифры из прошлого исследования в чате (требуют перепроверки): Twilio — исходящие
  в Азербайджан около $0.6257/мин на мобильные и $0.3989/мин на стационарные; на триале звонки только
  на верифицированные номера, ограниченный объём минут; для AZ нужно включить Geo Permissions.
  Vapi — $0.05/мин за платформу плюс STT/LLM/TTS (итого около $0.08–0.13/мин без стоимости
  телефонной сети), $5 стартовых кредитов; бесплатные номера Vapi — только США.
- Кандидаты: Twilio Programmable Voice (+ Media Streams для своего AI-движка), Telnyx Call Control,
  Plivo, Vonage; голосовые AI-платформы (Vapi, Retell) как отдельный тип адаптера; свой Asterisk или
  FreeSWITCH + платный SIP-транк (на Windows только Docker/WSL 2); экспериментально — звонки через
  собственный телефон и SIM по Bluetooth (`Hormold/agent-bluetooth`, MIT; официально только macOS и Linux).
- Вебхукам и медиапотокам нужен публичный HTTPS/WSS-адрес — на Windows это туннель
  (Cloudflare Tunnel, ngrok) **[проверить условия]**; в режиме симуляции не нужен.
- По каждому провайдеру фиксировать: покрытие +994 (мобильные/стационарные), KYC и верификацию,
  требования к caller ID, двустороннее аудио, подпись вебхуков, отмену вызова, цены, ограничения триала.

## 8. Голосовой движок: кандидаты (проверить на Phase 5)

## 10. Риски

| Риск | Влияние | Что делаем |
| --- | --- | --- |
| Звонки на +994 платные, триалы ограничены | бесплатно звонить на произвольные номера нельзя | mock и симуляция; выбор провайдера на Phase 4; никаких покупок без разрешения |
| Правила Азербайджана для автозвонков, согласия и записи | юридический риск | **[не проверено]** — до продакшна проверить нормы и политику провайдера |
| Caller ID: нужны свои или верифицированные номера; отображение международного номера в AZ | дозвоняемость и доверие | проверить на Phase 4; никакой подмены |
| Публичный URL на Windows для вебхуков и медиа | надёжность и безопасность | туннель и проверка подписей; в симуляции не нужен |
| Качество и задержка бесплатных и локальных моделей, особенно для азербайджанского | качество разговора | замеры на Phase 5; возможно, понадобятся платные облачные сервисы |
| Приватность бесплатных AI-уровней | утечка персональных данных | явный выбор провайдера, маскировка, ретеншн |
| Лимиты и задержки Notion API | задержки управления | polling с бэкоффом; состояние звонков хранится в локальной БД |
| В sandbox нет Windows | Windows-процесс может остаться непроверенным | CI на `windows-latest` и ручной чек-лист |
