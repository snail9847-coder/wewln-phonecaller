Поэтапный чек-лист разработки. Пункт отмечается `[x]` только при наличии доказательства
(коммит, вывод тестов, лог проверки). Неподтверждённые сведения помечены **[не проверено]**,
предложения по умолчанию — **[предложение]**, приблизительные оценки — **[оценка]**.

- **Статус:** Phase 1 (аудит) завершена 2026-11-03. Phase 2 (фундамент) и Phase 3 (Notion как
  пульт управления) выполнены 2026-11-03. Phase 4 (телефония): исследование (этап A) и код
  (этап B) выполнены 2026-11-04, PR #3 ждёт проверки владельца; звонок в телефонную сеть ещё не
  проверялся — нужен SIP-аккаунт и отдельное разрешение. Доказательства — в разделе 9. Phase 5
  (голосовой движок): код выполнен 2026-11-04, PR `phase-5-voice` → `phase-4-telephony`;
  разговор на ПК владельца и звонок в телефонную сеть ещё не проверялись.
- **Режим по умолчанию:** только симуляция. Реальные звонки, покупки и платные сервисы — только с явного разрешения.
- **Референс:** `risingpower/claude-phone@28efe1d` (MIT) — то же содержимое, что в загруженном `claude-phone-main.zip`.

## 1. Цель

Система исходящих AI-звонков на русском языке. Ею можно управлять из Notion, а запускается она
на Windows 10/11. Схема: контакты, сценарии и кампании → backend (оркестратор и проверки
безопасности) → адаптер телефонии (mock или реальный канал связи) → голосовой AI-движок
(STT → LLM → TTS, локально) → статусы, история диалогов и итоги в SQLite и копия в Notion.
Звонки на реальные внешние номера, в том числе российские (+7) и азербайджанские (+994), возможны
только в пределах возможностей выбранного канала связи и требований закона и только после явного
разрешения владельца.

### 1.1 Обязательные требования владельца (2026-11-03)

1. **Максимально бесплатно.** Бесплатные библиотеки и модели с открытым кодом, никаких обязательных
   платных API для STT, LLM и TTS. SQLite, официальный Notion API (токен), бесплатные тесты и CI.
2. **Русский язык обязателен.** Распознавание русской речи, ответы и естественный голос на русском,
   хранение истории диалога и итога, редактируемые сценарии. Архитектура расширяется на другие языки.
3. **Реальные внешние номера.** Исследовать бесплатные варианты: локальная АТС с открытым кодом
   (Asterisk и аналоги), SIP-провайдеры с бесплатным пробным балансом, существующий SIP-аккаунт
   с выходом в телефонную сеть. Честно разделять «бесплатное ПО» и «бесплатные минуты»
   и не обещать бесплатных звонков на мобильные и городские номера. Платный канал реализуется
   и проверяется в симуляции, платная телефония — опция. Отдельно проверить реальные варианты
   исходящих звонков на российские номера +7, не предполагая заранее, что они поддерживаются.
4. **Windows прежде всего.** Никаких зависимостей от macOS; учитывать требования локального ИИ к ОЗУ и железу.
5. **Notion — пульт управления:** контакты, сценарии, старт и стоп кампаний, статусы, результаты,
   ошибки, история. Backend работает и без Notion.

### 2.6 Вывод

claude-phone **не подходит как основа** wewln-phonecaller: главного (звонков на внешние номера,
Notion, кампаний, мер безопасности, Windows) в нём нет, а зависимость от macOS не даёт даже установить
пакет на другой ОС. Переиспользовать можно примерно 10–15 % кода: ARI-клиент, паттерны STT/TTS и подход к тестам.

**Решение D1:** новый репозиторий `wewln-phonecaller`; claude-phone остаётся внешним
референсом на `28efe1d`. Код переносится выборочно, в той фазе, где он нужен, с указанием источника
и текстом лицензии MIT в `THIRD_PARTY_NOTICES.md`. Форк не делаем: форк публичного репозитория
будет публичным и принесёт много нерелевантного кода.

## 3. Целевая архитектура

Текущее устройство и целевая схема описаны в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Кратко:

```text
Notion (пульт, необязателен)        локальный источник (CLI, файлы)
              └───────────────┬───────────────┘
                   control/: источник контактов, сценариев и кампаний
                              │
           orchestrator/ ── safety/ (режим, kill switch, arm, согласие, DNC, часы, лимиты)
                              │
           telephony/ ── mock │ SIP через свой Asterisk │ другие адаптеры (опция)
                              │  аудио и события звонка
           voice/ ── STT ⇄ LLM ⇄ TTS (локально, русский), сценарий, история, итог
                              │
           storage/ ── SQLite: кампании, контакты, сценарии, звонки, реплики, итоги, аудит
api/: aiohttp — /health, /ready, кампании, звонки, админ   ·   cli: wewln …
```

- **storage/repository.py** — единые правила для кампаний, контактов, «Не звонить» и заданий;
  ими пользуются и локальный режим (CLI, CSV, API), и синхронизация с Notion (решение D21).
  Источник истины о звонках — SQLite, Notion получает копию.
- **notion/** — REST-клиент на aiohttp с закреплённой версией `Notion-Version: 2026-03-11`;
  обработка 401/403/404/409/429/5xx и таймаутов, бэкофф по `Retry-After`; создание
  и проверка баз; цикл синхронизации (polling); имитация API для тестов.
- **core/** — модели pydantic: Contact, Script, Campaign, CallAttempt, Turn, CallSummary,
  ConsentRecord, SuppressionEntry; явные машины состояний.
- **telephony/** — протокол `TelephonyProvider`: `place_call`, `cancel_call`, `get_status`,
  `parse_event`; `MockProvider` со сценариями «ответил», «занято», «не ответил», «ошибка»,
  «автоответчик», «обрыв посреди разговора».
- **voice/** — интерфейсы `STT`, `LLM`, `TTS` и `ConversationEngine`:
  GREETING → DISCLOSURE → PURPOSE → DIALOG (LISTENING ⇄ THINKING ⇄ SPEAKING) → CLOSING → ENDED,
  ветки OPT_OUT и ERROR; barge-in, таймауты, реплики с отметками времени, итог по JSON-схеме.
- **Языки** — реестр `SUPPORTED_LANGUAGES`; для каждого языка задаются модель STT, голос TTS,
  подсказки LLM и фразы отказа. Первым идёт `ru-RU`.
- **cli** — сейчас `serve | check-config | init-db | notion … | campaign … | contacts … | jobs |
  dnc … | simulate`; позже `doctor | arm | disarm | kill-switch | purge`.

## 5. Модель безопасности звонков

- `simulation` по умолчанию: реальный провайдер недоступен.
- Реальный звонок возможен, только если выполнены все условия:
  1. `WEWLN_MODE=production`;
  2. `WEWLN_PRODUCTION_CONFIRM` совпадает с точной фразой подтверждения;
  3. kill switch выключен;
  4. выбранный провайдер умеет реальные звонки (`places_real_calls`);
  5. у кампании отмечено «Реальные звонки разрешены»;
  6. оператор выполнил `wewln arm --campaign <id> --ttl 30m` (запись со сроком действия в audit log).

  Условия 1–4 и «оператор не взвёл систему» реализованы в Phase 2 (`safety.py`). Phase 4
  добавила: провайдер настроен, задан `WEWLN_CALL_REGIONS`, аварийная остановка во время работы
  (`wewln calls stop-all`) и единственный пока способ «взвода» — разовое разрешение на тестовый
  звонок на один номер (`wewln calls permit`). Условие 5 и команда `arm` для кампаний появятся
  в Phase 6; до этого реальные звонки кампаний закрыты всегда.
- Kill switch (env, позже файл, API и Notion) сразу блокирует новые наборы; активные звонки завершаются штатно.
- Перед каждым набором: валидный E.164; страна в allowlist (+7 и +994 включаются явно); номера нет
  в suppression/DNC; есть согласие или иное законное основание, если этого требует политика кампании;
  время в окне звонков по часовому поясу получателя (по умолчанию 10:00–19:00 **[предложение]**);
  соблюдены лимиты частоты на контакт; caller ID из утверждённого списка; лимиты конкурентности и скорости.
- Защита от случайных дублей: идемпотентный старт кампании, отпечаток «контакты + цель + окно».
- В начале разговора AI честно говорит, что это автоматический звонок с ИИ, от чьего имени и зачем.
  На «не звоните мне» или «стоп» — вежливое завершение и автодобавление в suppression.
- Запись разговора выключена по умолчанию; если включена — объявление о записи до начала разговора.
- Ретеншн транскриптов и контактных данных настраивается (по умолчанию 30 дней **[предложение]**),
  удаление командой `purge`; номера в логах и аудите маскируются (реализовано в Phase 2).
- Никаких функций для обхода антиспама, подмены caller ID, обхода согласия или ограничений провайдера.

## 6. Схема Notion (реализована на Phase 3)

Четыре базы под одной страницей; их создаёт `wewln notion bootstrap`. Полное описание свойств,
правила и пошаговое подключение — в [docs/NOTION.md](docs/NOTION.md).

- **Кампании (wewln):** Название, Статус (Черновик / Запущена / Пауза / Остановлена / Завершена),
  Сценарий, Язык, Макс. попыток; wewln пишет Сводку и Ошибку.
- **Контакты (wewln):** Имя, Телефон, Не звонить, Причина запрета, Кампании (связь); wewln пишет
  Ошибку (проблемы с номером).
- **Задания на звонки (wewln)** — ведёт wewln: Кампания, Контакт, Статус (В очереди /
  Заблокировано / Выполняется / Выполнено / Ошибка / Отменено), Причина, Попытки, Ключ,
  Обновлено, Симуляция.
- **Результаты звонков (wewln)** — ведёт wewln: Задание, Кампания, Контакт, Исход, Начало,
  Длительность, Итог, Ключ, Симуляция.

Отложено до фаз 5–6 (из черновика схемы): отдельная база сценариев с версиями, согласие
и его источник, часовой пояс и окно звонков, страны, caller ID, режим и «Реальные звонки
разрешены» у кампании, история диалога в теле страницы, отдельная база suppression (сейчас
«Не звонить» — флажок у контакта плюс локальный список), страница Control с kill switch.

Проверено по документации Notion API (2026-11-03): версия `2026-03-11` работает с data
sources; лимит запросов на подключение — 180 в минуту на тарифах Free и Plus и 600 в минуту на

## 7. Телефония (исследовано на Phase 4)

Итоги исследования от 2026-11-03 с источниками — в [docs/PROVIDERS.md](docs/PROVIDERS.md),
установка Asterisk и первый звонок — в [docs/ASTERISK.md](docs/ASTERISK.md).

- Бесплатное ПО и бесплатные минуты — разные вещи. Asterisk, софтфон и wewln бесплатны, а звонок
  на внешний мобильный или городской номер идёт через телефонную сеть и почти всегда платный.
  Проект этого не скрывает и бесплатных звонков на такие номера не обещает.
- Подтверждено: бесплатно звонить на внешние +7 и +994 нельзя; пробные периоды Twilio, Telnyx и
  Vonage — только на свой подтверждённый номер, у SignalWire в пробном режиме нет международных
  звонков; Asterisk 22 LTS ставится в WSL2 из пакетов Ubuntu 26.04; в России автоматические
  звонки требуют предварительного согласия абонента.
- Выбрано (D11, D24): свой Asterisk в WSL2 и SIP-транк любого провайдера; wewln управляет
  Asterisk через ARI. Asterisk звонит через транк исходящими соединениями, поэтому публичный
  адрес не нужен. Облачные голосовые API — позже и только по желанию владельца.
- Своя SIM через GSM-шлюз — только эксперимент: операторы часто запрещают автоматические звонки
  и шлюзы **[не проверено]**.
- Не подтверждено: звонки пробных периодов на +994 и +7, минимальное пополнение Zadarma, пометки
  российских операторов, правила Казахстана и нерекламных автозвонков в Азербайджане. Звонок в
  телефонную сеть ещё не сделан.
- На Phase 5: аудиопоток звонка для голосового движка (ARI External Media или AudioSocket),
  кодеки и звук 8 кГц.

- Железо **[оценка, проверить на ПК владельца в Phase 5]**: минимум — 4 ядра CPU и 16 ГБ ОЗУ
  (Vosk или faster-whisper small на CPU, LLM 3–4B в 4-битной квантизации, Piper или RHVoice);
  задержка ответа, вероятно, несколько секунд. Для живого диалога желательна видеокарта NVIDIA
  с 8 ГБ VRAM и больше (faster-whisper large-v3-turbo, LLM 7–8B).

  на телефонном аудио 8 кГц, естественность бесплатных русских голосов, качество русского у LLM на CPU.
- Облачные STT, LLM и TTS не требуются; если владелец захочет, они подключаются как опциональные
  адаптеры (бесплатные уровни облаков могут использовать данные разговоров — важно для приватности).

**Итог Phase 5 (2026-11-04)** — выбор D12, подробности в [docs/VOICE.md](docs/VOICE.md):

- Замеры в Linux-песочнице, 2 vCPU, без GPU: загрузка Vosk 1,2 с, Piper 3–4 с; Piper

  `qwen3:0.6b` после прогрева даёт первые слова за 0,6–2 с. От конца реплики до начала ответа:
  1,0–1,4 с без LLM, 2,9–5,5 с с `qwen3:0.6b`. Цель ~1,5 с на таком железе с LLM не достигнута;
  на ПК владельца не замерено.
- Распознавание синтезированной речи Piper на 8 кГц маленькой моделью Vosk: 80–100 % слов для
  простых фраз, на отдельных фразах — 33–50 %. Живая речь по телефону не проверялась.
- `qwen3:0.6b` отвечает слабо и повторяется — по умолчанию `qwen3:4b` (≈ 2,5 ГБ) **[не проверено]**.
- Лицензии: Vosk и модель — Apache-2.0; `piper-tts` 1.3+ — GPL-3.0; набор записей голоса
  `denis` — CC0, но все русские голоса Piper дообучены из `lessac` (Blizzard 2013: только
  исследования, без коммерческого использования) — для коммерции голос нужно проверить или заменить.
- Не оценивались на этой фазе: sherpa-onnx, RHVoice, Silero, faster-whisper на телефонном звуке.

## 10. Риски

| Риск | Влияние | Что делаем |
| --- | --- | --- |
| Минуты в телефонную сеть платные, пробные балансы малы | бесплатно звонить на внешние номера нельзя | симуляция и звонки на свой софтфон; платный канал — только по решению владельца |
| Звонки на +7 могут не поддерживаться выбранным каналом | недоступность главного направления | у найденных провайдеров направление есть в тарифах ([docs/PROVIDERS.md](docs/PROVIDERS.md)); реальный звонок не проверен; российские операторы могут блокировать звонки из-за рубежа |
| Правила России и Азербайджана для автозвонков, согласия, рекламы и записи | юридический риск | основные нормы найдены ([docs/PROVIDERS.md](docs/PROVIDERS.md#закон)): в России — только с согласия абонента; до продакшна — юрист и правила провайдера |
| Caller ID и антиспам-фильтры операторов | дозвоняемость и доверие | только свой номер у провайдера (`WEWLN_CALLER_ID`), никакой подмены; пометки операторов **[не проверено]** |
| Железо ПК владельца для локальных моделей | задержка и качество разговора | на 2 vCPU ответ через 3–5,5 с с маленькой LLM (раздел 8); замер на ПК владельца — `wewln voice check` и `voice simulate`; меньше модель или GPU |
| Лицензии голосов и моделей (GPL, некоммерческие) | ограничения использования | проверено на Phase 5: `piper-tts` — GPL-3.0, русские голоса Piper происходят от `lessac` (только исследования) — для коммерции заменить голос или получить заключение юриста ([docs/VOICE.md](docs/VOICE.md)) |
| Эхо и шум на линии, распознавание телефонной речи | бот перебивает сам себя, ошибки распознавания | защита от эха и порог по шуму (тесты), переспрашивание; на живой линии не проверено |
| Asterisk не работает в Windows нативно | сложнее установка | WSL2 и пошаговая инструкция [docs/ASTERISK.md](docs/ASTERISK.md); на ПК владельца ещё не проверено; скрипты — на Phase 7 |
| Звонки проверены только на имитации ARI и на настоящем Asterisk с Local-каналами | SIP-транк, звук и причины от провайдера могут вести себя иначе | первый звонок на свой номер по разрешению владельца; разбор причин в [docs/ASTERISK.md](docs/ASTERISK.md) |
| Квота минут GitHub Actions, если репозиторий приватный | CI может остановиться | компактная матрица; минуты Windows дороже Linux; для публичного репозитория стандартные раннеры бесплатны |
| В sandbox нет Windows | Windows-процесс может остаться непроверенным | CI на `windows-latest` и ручной чек-лист на ПК владельца |
| Интеграция проверена только на имитации Notion API | настоящий API может отличаться в деталях | версия API закреплена, `wewln notion check`, чек-лист ручной проверки в docs/TESTING.md |
| Бесплатное пространство Notion с несколькими участниками: 1000 блоков за всё время | создание заданий и результатов остановится (403 `restricted_resource`) | предупреждение в docs/NOTION.md; на платных тарифах ограничения нет |
| Большие базы в Notion (тысячи контактов) | цикл синхронизации долгий, ближе к лимитам API | лимит скорости 2,5 запроса в секунду; при необходимости — инкрементальное чтение по `last_edited_time` (позже) |
| Имена и номера контактов в SQLite и в Notion | персональные данные на диске и в облаке Notion | маскировка в логах, аудите и выводе; доступ к папке `data\` только у владельца; `purge` на Phase 6 |

### Открытые вопросы владельцу (Phase 5 не блокируют)
