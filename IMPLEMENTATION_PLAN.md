# IMPLEMENTATION_PLAN — wewln-phonecaller

Поэтапный чек-лист разработки. Пункт отмечается `[x]` только при наличии доказательства
(коммит, вывод тестов, лог проверки). Неподтверждённые сведения помечены **[не проверено]**,
предложения по умолчанию — **[предложение]**, приблизительные оценки — **[оценка]**.

- **Статус:** Phase 1 (аудит) завершена 2026-11-03. Phase 2 (фундамент) выполнена 2026-11-03,
  доказательства — в разделе 9. Phase 3 не начата: ждёт явного разрешения владельца.
- **Режим по умолчанию:** только симуляция. Реальные звонки, покупки и платные сервисы — только с явного разрешения.
- **Референс:** `risingpower/claude-phone@28efe1d` (MIT) — то же содержимое, что в загруженном `claude-phone-main.zip`.

## 1. Цель

Система исходящих AI-звонков на русском языке. Ею можно управлять из Notion, а запускается она
на Windows 10/11. Схема: контакты, сценарии и кампании → backend (оркестратор и проверки
безопасности) → адаптер телефонии (mock или реальный канал связи) → голосовой AI-движок
(STT → LLM → TTS, локально) → статусы, история диалогов и итоги в SQLite и копия в Notion.
Звонки на реальные внешние номера, в том числе российские (+7) и азербайджанские (+994), возможны
только в пределах возможностей выбранного канала связи и требований закона и только после явного
разрешения владельца.

### 1.1 Обязательные требования владельца (2026-11-03)

1. **Максимально бесплатно.** Бесплатные библиотеки и модели с открытым кодом, никаких обязательных
   платных API для STT, LLM и TTS. SQLite, официальный Notion API (токен), бесплатные тесты и CI.
2. **Русский язык обязателен.** Распознавание русской речи, ответы и естественный голос на русском,
   хранение истории диалога и итога, редактируемые сценарии. Архитектура расширяется на другие языки.
3. **Реальные внешние номера.** Исследовать бесплатные варианты: локальная АТС с открытым кодом
   (Asterisk и аналоги), SIP-провайдеры с бесплатным пробным балансом, существующий SIP-аккаунт
   с выходом в телефонную сеть. Честно разделять «бесплатное ПО» и «бесплатные минуты»
   и не обещать бесплатных звонков на мобильные и городские номера. Платный канал реализуется
   и проверяется в симуляции, платная телефония — опция. Отдельно проверить реальные варианты
   исходящих звонков на российские номера +7, не предполагая заранее, что они поддерживаются.
4. **Windows прежде всего.** Никаких зависимостей от macOS; учитывать требования локального ИИ к ОЗУ и железу.
5. **Notion — пульт управления:** контакты, сценарии, старт и стоп кампаний, статусы, результаты,
   ошибки, история. Backend работает и без Notion.

### 2.2 Что это за проект

claude-phone — локальная мини-АТС на одном Mac. Asterisk 22 (собирается из исходников) соединяет
**собственный настольный SIP-телефон владельца** (Yealink T31P или Linphone в той же локальной сети)
с сессиями Claude Code в iTerm2. Claude звонит владельцу через MCP-инструменты `call_<owner>` и
`notify_<owner>`, владелец звонит сессиям по внутренним номерам 301–399; есть голосовая почта,
оператор «0», игра Crack the Safe и управление лампами Govee. README прямо пишет: «Mac only (Apple Silicon)».

- Пакет `claude_phone/`: 22 файла, около 3 590 строк Python; 8 шаблонов Asterisk; 3 документа;
  8 файлов тестов (около 600 строк, 51 тест). Лицензия MIT © 2026 risingpower.
- Зависимости (`pyproject.toml`): Python ≥ 3.12; `aiohttp>=3.9`, `mcp>=2.3,<3`,
  `pyobjc-framework-EventKit>=10`; dev: `pytest>=8`.
- Внешние компоненты: Asterisk 22.11 (`scripts/build-asterisk.sh` с патчами под macOS и Homebrew),
  whisper.cpp `whisper-server`, macOS `say` и `afconvert`; опционально ElevenLabs, ntfy.sh, Govee LAN API.
- Issues/PR upstream: 1 открытый issue (совместимость с Yealink T26P), открытый PR #1 (голоса Siri),
  закрытый без слияния PR #3 «Run on Windows (WSL 2) and with analog phones» (643+/88−, 18 файлов, 2026-10-23).
  PR #3 не входит в zip и не прошёл ревью.

### 2.4 Несовместимые допущения

#### A. Звонит только собственному SIP-телефону (выхода в телефонную сеть нет)

- `claude_phone/daemon.py:591` — единственный исходящий вызов: `POST /channels` с
  `endpoint=f"PJSIP/{ring_ext}"`, то есть внутренний номер 200 или 201.
- `asterisk/pjsip.conf.tmpl` — только LAN-эндпоинты 200/201 и ACL `deny=0.0.0.0/0` +
  `permit=@@LAN_CIDR@@`; нет SIP-транка, регистрации у оператора и outbound proxy.
- `asterisk/extensions.conf.tmpl` — единственный контекст `from-desk`, всё уходит в Stasis.
- Нет E.164, проверки номеров и настоящего caller ID (вместо него подпись `repo/branch`).

#### B. Привязка к macOS

| Где | Что | Чем заменить в wewln-phonecaller |
| --- | --- | --- |
| `inject.py` | AppleScript (`osascript`) → iTerm2 | не нужно, вне задачи |
| `tts.py:25`, `tts.py:36` | `afconvert`, `say` | кроссплатформенный TTS-адаптер и ресемплинг в Python |
| `keychain.py` | `security` (Keychain) | переменные окружения и `.env`; опционально Windows Credential Manager через `keyring` |
| `cli.py:112–235` | launchd/`launchctl`, `~/Library/LaunchAgents`, пути `/opt/homebrew` | `python -m wewln_phonecaller serve`, PowerShell-скрипты |
| `config.py:127–141` | `route -n get default`, `ipconfig getifaddr`, `ifconfig` | не нужно (нет телефона в LAN) |
| `diary.py`, `pyproject.toml` | EventKit через PyObjC | не нужно; блокирует установку вне macOS |
| `scripts/build-asterisk.sh`, `docs/build-notes.md` | сборка под `aarch64-apple-darwin`, openssl из Homebrew | если понадобится Asterisk — Docker или WSL 2 |
| `config.py:19` | `ASTERISK_RUN=/tmp/cphone` (лимит длины unix-сокета macOS) | не нужно |

#### C. Остальные расхождения с требованиями

- Одна линия: `daemon.py:93` — `self.line = asyncio.Lock()` («one call with the owner at a time»).
  Нет кампаний, очередей, конкурентности, расписаний и повторов.
- Только английский: `whisper-server ... -l en` (`cli.py:113`), фильтр «шумовых» фраз STT на английском,
  британские голоса.
- Нет Notion, контактов, согласий, DNC/suppression, часов звонков, лимитов частоты, kill switch,
  разделения симуляции и продакшна.
- HTTP API демона (`127.0.0.1:8765`: `/call`, `/notify`, `/transfer` …) без аутентификации —
  защищён только тем, что слушает localhost.
- Логи — обычный текст (`log.py`) с транскриптами; нет структурированных логов и correlation ID.
  Записи и кэш речи удаляются через 30 дней (`housekeeping.py`), журнал инъекций в БД не чистится.
- Аудио рассчитано на LAN (G.722, 16 кГц); в телефонной сети обычно G.711 8 кГц (μ-law/A-law).
  Модуль `audioop` удалён из Python 3.13, поэтому конвертацию надо делать без него.
- Asterisk нативно на Windows не работает — только через WSL 2 или Docker
  **[общеизвестно, в этом проекте не проверялось]**.

### 2.6 Вывод

claude-phone **не подходит как основа** wewln-phonecaller: главного (звонков на внешние номера,
Notion, кампаний, мер безопасности, Windows) в нём нет, а зависимость от macOS не даёт даже установить
пакет на другой ОС. Переиспользовать можно примерно 10–15 % кода: ARI-клиент, паттерны STT/TTS и подход к тестам.

**Решение D1:** новый приватный репозиторий `wewln-phonecaller`; claude-phone остаётся внешним
референсом на `28efe1d`. Код переносится выборочно, в той фазе, где он нужен, с указанием источника
и текстом лицензии MIT в `THIRD_PARTY_NOTICES.md`. Форк не делаем: форк публичного репозитория
будет публичным и принесёт много нерелевантного кода.

## 3. Целевая архитектура

Текущее устройство и целевая схема описаны в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Кратко:

```text
Notion (пульт, необязателен)        локальный источник (CLI, файлы)
              └───────────────┬───────────────┘
                   control/: источник контактов, сценариев и кампаний
                              │
           orchestrator/ ── safety/ (режим, kill switch, arm, согласие, DNC, часы, лимиты)
                              │
           telephony/ ── mock │ SIP через свой Asterisk │ другие адаптеры (опция)
                              │  аудио и события звонка
           voice/ ── STT ⇄ LLM ⇄ TTS (локально, русский), сценарий, история, итог
                              │
           storage/ ── SQLite: кампании, контакты, сценарии, звонки, реплики, итоги, аудит
api/: aiohttp — /health, /ready, кампании, звонки, админ   ·   cli: wewln …
```

- **control/** — единый интерфейс источника данных с двумя реализациями: Notion (официальный API,
  polling) и локальная (CLI и файлы). Источник истины о звонках — SQLite, Notion получает копию.
- **notion/** — REST-адаптер на aiohttp с закреплённой версией `Notion-Version`; обработка
  401/403/404/409/429/5xx, бэкофф по `Retry-After`.
- **core/** — модели pydantic: Contact, Script, Campaign, CallAttempt, Turn, CallSummary,
  ConsentRecord, SuppressionEntry; явные машины состояний.
- **telephony/** — протокол `TelephonyProvider`: `place_call`, `cancel_call`, `get_status`,
  `parse_event`; `MockProvider` со сценариями «ответил», «занято», «не ответил», «ошибка»,
  «автоответчик», «обрыв посреди разговора».
- **voice/** — интерфейсы `STT`, `LLM`, `TTS` и `ConversationEngine`:
  GREETING → DISCLOSURE → PURPOSE → DIALOG (LISTENING ⇄ THINKING ⇄ SPEAKING) → CLOSING → ENDED,
  ветки OPT_OUT и ERROR; barge-in, таймауты, реплики с отметками времени, итог по JSON-схеме.
- **Языки** — реестр `SUPPORTED_LANGUAGES`; для каждого языка задаются модель STT, голос TTS,
  подсказки LLM и фразы отказа. Первым идёт `ru-RU`.
- **cli** — сейчас `serve | check-config | init-db`; позже `doctor | simulate | notion bootstrap |
  campaign … | arm | disarm | kill-switch | purge`.

## 5. Модель безопасности звонков

- `simulation` по умолчанию: реальный провайдер недоступен.
- Реальный звонок возможен, только если выполнены все условия:
  1. `WEWLN_MODE=production`;
  2. `WEWLN_PRODUCTION_CONFIRM` совпадает с точной фразой подтверждения;
  3. kill switch выключен;
  4. выбранный провайдер умеет реальные звонки (`places_real_calls`);
  5. у кампании отмечено «Реальные звонки разрешены»;
  6. оператор выполнил `wewln arm --campaign <id> --ttl 30m` (запись со сроком действия в audit log).

  Условия 1–4 и «оператор не взвёл систему» реализованы в Phase 2 (`safety.py`). Условие 5
  и команда `arm` появятся в Phase 6; до этого гейт всегда закрыт.
- Kill switch (env, позже файл, API и Notion) сразу блокирует новые наборы; активные звонки завершаются штатно.
- Перед каждым набором: валидный E.164; страна в allowlist (+7 и +994 включаются явно); номера нет
  в suppression/DNC; есть согласие или иное законное основание, если этого требует политика кампании;
  время в окне звонков по часовому поясу получателя (по умолчанию 10:00–19:00 **[предложение]**);
  соблюдены лимиты частоты на контакт; caller ID из утверждённого списка; лимиты конкурентности и скорости.
- Защита от случайных дублей: идемпотентный старт кампании, отпечаток «контакты + цель + окно».
- В начале разговора AI честно говорит, что это автоматический звонок с ИИ, от чьего имени и зачем.
  На «не звоните мне» или «стоп» — вежливое завершение и автодобавление в suppression.
- Запись разговора выключена по умолчанию; если включена — объявление о записи до начала разговора.
- Ретеншн транскриптов и контактных данных настраивается (по умолчанию 30 дней **[предложение]**),
  удаление командой `purge`; номера в логах и аудите маскируются (реализовано в Phase 2).
- Никаких функций для обхода антиспама, подмены caller ID, обхода согласия или ограничений провайдера.

## 6. Черновик схемы Notion (уточняется на Phase 3)

- **Campaigns:** Name, Status (Draft/Scheduled/Running/Paused/Stopped/Completed), Command (Start/Pause/Stop),
  Mode (Simulation/Production), Real calls approved, Script, Language, Caller ID, Calling window,
  Allowed countries, Max attempts, Retry delay, Max concurrent calls, Recording, Start/End, Contacts, Calls, Last error.
- **Contacts:** Name, Phone (как введён), Phone E.164 (заполняет backend), Country, Time zone,
  Consent status, Consent source/date, Do not call, Campaigns, Last called, Attempts.
- **Scripts:** Name, Language, Purpose, Greeting and disclosure, Instructions, Allowed facts,
  Forbidden topics, Opt-out phrases, Version, Status (Draft/Approved). Текст сценария — в теле
  страницы, чтобы его было удобно редактировать.
- **Calls:** Title, Campaign, Contact, Script version, Simulated, Status (Queued/Dialing/Ringing/
  In progress/Completed/No answer/Busy/Failed/Canceled/Blocked), Outcome, Started/Ended, Duration,
  Attempt, Error, Summary, Opt-out requested; история диалога (реплики) — в теле страницы с учётом ретеншна.
- **Suppression:** Phone E.164, Reason (Opt-out/DNC/Manual/Complaint), Source, Added at.
- **Control:** Kill switch и текущий режим (решение всё равно принимает backend).

Интеграции Notion нужно выдать доступ к этим базам; токен хранится только в `WEWLN_NOTION_TOKEN`.
Лимит Notion API — в среднем около 3 запросов в секунду на интеграцию **[проверить на Phase 3]**;
в новых версиях API базы данных разделены на data sources — версию выбрать на Phase 3 **[проверить]**.

## 7. Телефония: варианты и вопросы (проверить на Phase 4)

### 7.1 Бесплатное ПО и бесплатные минуты — разные вещи

| Вариант | ПО | Минуты | Что даёт |
| --- | --- | --- | --- |
| Свой Asterisk + софтфон (MicroSIP, Linphone, Zoiper) в своей сети | бесплатно, открытый код | бесплатно (нет телефонной сети) | реальный звонок с живым голосом на русском, но только на свой софтфон, не на внешний номер |
| Свой Asterisk + SIP-провайдер с пробным балансом | бесплатно | пробный баланс обычно мал и ограничен (например, звонки только на подтверждённые номера) **[проверить по каждому провайдеру]** | короткие проверки на реальные номера |
| Свой Asterisk + существующий SIP-аккаунт владельца с выходом в телефонную сеть | бесплатно | по тарифу владельца | реальные внешние номера |
| Облачные голосовые API (Twilio, Telnyx, Plivo, Vonage и т. п.) | платный сервис | платно | реальные номера; опциональный адаптер, не по умолчанию |
| Своя SIM через GSM-шлюз | бесплатно (шлюз — оборудование) | по тарифу SIM | операторы часто запрещают автоматизированные звонки и шлюзы **[проверить условия оператора]**; экспериментально |

Звонки на мобильные и городские номера через телефонную сеть платные почти всегда. Проект это
не скрывает и не обещает бесплатных звонков на такие номера.

Asterisk (`asterisk/asterisk`, репозиторий активен на 2026-11-02; GitHub не определяет лицензию
автоматически, у проекта GPL-2.0 с исключениями **[проверить формулировку]**) не работает в Windows
нативно — только в WSL2 или Docker. Свой SIP-стек на Python (`tayler6000/pyVoIP`, GPL-3.0, только
PCMA/PCMU, последний push 2025-03-04) — запасной вариант с риском зрелости.

### 7.2 Звонки на российские номера +7 — проверить, ничего не предполагая

- Какие провайдеры действительно доставляют исходящие звонки на мобильные и городские +7 при
  звонке из-за пределов России; есть ли у зарубежных провайдеров ограничения на это направление **[не проверено]**.
- Российские провайдеры SIP и виртуальных АТС: можно ли подключиться нерезиденту (из Азербайджана),
  какие документы нужны (паспорт, юрлицо, KYC) **[не проверено]**.
- Регулирование в России: требования к звонкам организаций (маркировка, антифрод-системы,
  отказ абонентов от таких звонков), согласие абонента на рекламу, ограничения автоматического
  дозвона **[не проверено юридически — нужны первоисточники и, вероятно, юрист]**.
- Отображение номера: звонки с иностранных номеров на +7 могут блокироваться или помечаться
  как спам **[не проверено]**.
- Цены за минуту на мобильные и городские номера России у реальных провайдеров **[не проверено]**.

### 7.3 Азербайджан (+994) и другие направления

- Предварительные цифры из прошлого исследования в чате (требуют перепроверки): Twilio — исходящие
  в Азербайджан около $0.6257/мин на мобильные и $0.3989/мин на стационарные; на триале звонки только
  на верифицированные номера; для AZ нужно включить Geo Permissions. Vapi — $0.05/мин за платформу
  плюс STT/LLM/TTS, $5 стартовых кредитов **[не проверено]**.
- Правила Азербайджана для автозвонков, согласия и записи **[не проверено]**.

### 7.4 Техническая интеграция

- Asterisk ARI + External Media или AudioSocket: backend на Python получает и отдаёт аудиопоток
  звонка **[проверить на Phase 4]**.
- Свой Asterisk звонит через SIP-транк исходящими соединениями, поэтому публичный URL не нужен;
  NAT и RTP-порты требуют настройки **[проверить]**. Облачным провайдерам нужны публичные
  HTTPS/WSS-адреса (туннель).
- По каждому варианту фиксировать: покрытие +7 и +994 (мобильные и городские), KYC, caller ID,
  кодеки и качество аудио (8 кГц), отмену вызова, цены, ограничения пробного баланса.

## 8. Голосовой движок: бесплатные локальные кандидаты (проверить на Phase 5)

Данные GitHub на 2026-11-03; лицензия — это лицензия кода, у моделей и голосов лицензии бывают свои.

| Задача | Кандидат | Лицензия кода | Активность | Заметки |
| --- | --- | --- | --- | --- |
| STT | `SYSTRAN/faster-whisper` | MIT | активен | Whisper многоязычный, русский есть; CPU (int8) или NVIDIA GPU |
| STT | `ggml-org/whisper.cpp` | MIT | активен | нативно на Windows, есть HTTP-сервер |
| STT | `alphacep/vosk-api` | Apache-2.0 | активен | лёгкий потоковый; есть русские модели; качество ниже Whisper **[проверить]** |
| STT, TTS, VAD | `k2-fsa/sherpa-onnx` | Apache-2.0 | активен | один ONNX-рантайм; русские модели **[проверить]** |
| LLM | `ollama/ollama` | MIT | активен | есть версия для Windows; у моделей (Qwen, Gemma, Llama и др.) разные лицензии и разное качество русского **[проверить]** |
| TTS | `rhasspy/piper` | MIT | **архивирован** (2025-08-26) | развитие перенесено в `OHF-Voice/piper1-gpl` |
| TTS | `OHF-Voice/piper1-gpl` | GPL-3.0 | активен | есть голоса `ru_RU` **[проверить]**; GPL — запускать отдельным процессом и учесть при распространении |
| TTS | `RHVoice/RHVoice` | GPL-2.0 | активен | создан в том числе для русского; лицензии голосов отдельные **[проверить]** |
| TTS | `snakers4/silero-models` | своя (GitHub: NOASSERTION) | активен | качественный русский; возможны ограничения коммерческого использования **[проверить]** |
| Каркас голосового агента | `pipecat-ai/pipecat` | BSD-2-Clause | активен | оценить как основу конвейера STT → LLM → TTS **[предложение]** |

- Железо **[оценка, проверить на ПК владельца в Phase 5]**: минимум — 4 ядра CPU и 16 ГБ ОЗУ
  (Vosk или faster-whisper small на CPU, LLM 3–4B в 4-битной квантизации, Piper или RHVoice);
  задержка ответа, вероятно, несколько секунд. Для живого диалога желательна видеокарта NVIDIA
  с 8 ГБ VRAM и больше (faster-whisper large-v3-turbo, LLM 7–8B).
- Целевая задержка ответа — до ~1,5 с **[предложение]**. Главные риски: распознавание русской речи
  на телефонном аудио 8 кГц, естественность бесплатных русских голосов, качество русского у LLM на CPU.
- Облачные STT, LLM и TTS не требуются; если владелец захочет, они подключаются как опциональные
  адаптеры (бесплатные уровни облаков могут использовать данные разговоров — важно для приватности).
