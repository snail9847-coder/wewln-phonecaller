# Безопасность

## Реальные звонки заблокированы по умолчанию

Реальный звонок возможен только при выполнении **всех** условий сразу (`src/wewln_phonecaller/safety.py`):

1. `WEWLN_MODE=production`;
2. `WEWLN_PRODUCTION_CONFIRM=I_ACCEPT_REAL_CALLS`;
3. kill switch выключен (`WEWLN_KILL_SWITCH=false`);
4. выбранный провайдер телефонии умеет звонить на реальные номера;
5. оператор явно «взвёл» систему (команда `arm` с ограниченным сроком появится в фазе 6).

В этой версии есть только провайдер `mock`, а `arm` ещё не реализован, поэтому реальные звонки
невозможны при любых настройках. Текущее состояние видно в `check-config` (`real_calls_allowed`)
и в `/ready` (`checks.real_calls`).

## Секреты

- Секреты хранятся только в переменных окружения или в `.env`, который исключён из git.
- В коде токены — `SecretStr`. В выводе CLI, в ответах API и в логах вместо них стоит `set` или `***`.
- Сообщения об ошибках настроек называют переменную, но не показывают её значение.
- Сравнение токена API — за постоянное время (`hmac.compare_digest`).

## Сеть

- HTTP API по умолчанию слушает только `127.0.0.1`.
- Если указать адрес не из loopback без `WEWLN_API_TOKEN`, программа откажется запускаться.
- Всё, кроме `/health` и `/ready`, требует Bearer-токен. Без настроенного токена эти эндпоинты
  закрыты (fail closed).
- Ответы об ошибках не раскрывают внутренние детали; подробности есть только в логе, по `request_id`.

## Персональные данные

- Номера телефонов маскируются в логах и в журнале аудита до записи на диск: остаются только
  первые две и последние две цифры (`+79*******67`).
- Записи разговоров, транскрипты и срок их хранения появятся в фазах 5–6. Запись будет
  выключена по умолчанию.

## Чего в проекте не будет

Функций для подмены номера (caller ID spoofing), обхода антиспам-систем, согласия абонентов
или ограничений провайдеров.

## Как сообщить о проблеме

Репозиторий приватный. О найденной уязвимости сообщите владельцу напрямую, не в открытом issue,
и не прикладывайте реальные токены или номера.
