# wewln-phonecaller

Исходящие голосовые звонки с ИИ на русском языке. Управление — из Notion или без него,
запуск — на Windows 10/11. По умолчанию работает только симуляция: реальные звонки
заблокированы, пока владелец явно их не разрешит.

> **Статус: фаза 2 — фундамент.** Готов каркас backend: настройки, SQLite, логи с маскировкой
> номеров, HTTP-проверки `/health` и `/ready`, тесты и CI на Windows и Linux. Самих звонков
> (реальных и симулированных разговоров), распознавания и синтеза речи, LLM и интеграции
> с Notion пока **нет**. Они появятся в следующих фазах — см. [план](IMPLEMENTATION_PLAN.md).

## Что уже работает

- `check-config` проверяет настройки и печатает их без секретов. Заодно показывает, почему
  реальные звонки заблокированы.
- `init-db` создаёт или обновляет базу SQLite (журнал WAL, миграции в транзакциях).
- `serve` поднимает локальный HTTP API на `127.0.0.1:8787` с эндпоинтами `/health`, `/ready`
  и защищённым токеном `/api/v1/info`.
- Логи в формате JSON или текстом — в консоль и в файл с ротацией. У каждого запроса свой
  `request_id`; номера телефонов и токены маскируются (`+79*******67`).
- Журнал аудита в SQLite фиксирует запуск и остановку; номера в нём тоже маскируются.
- Гейт реальных звонков. В этой версии он закрыт при любых настройках: есть только провайдер `mock`.

## Принципы

- **Бесплатный стек.** Только бесплатные библиотеки с открытым кодом и локальные модели, без
  обязательных платных API. Платные сервисы (например, минуты телефонной сети) подключаются
  только по желанию владельца.
- **Русский язык обязателен.** Язык по умолчанию — `ru-RU`. Список языков расширяемый.
- **Windows прежде всего**, без зависимостей от macOS.
- **Notion — пульт управления, но не обязательная часть.** Backend работает и без Notion.
- **Безопасность по умолчанию.** Режим `simulation`, kill switch, отказ запускаться
  с опасными или неполными настройками.

## Установка и запуск на Windows 10/11

1. Установите Python 3.12, 3.13 или 3.14 (64-bit) с [python.org](https://www.python.org/downloads/windows/).
   В установщике отметьте «Add python.exe to PATH». Проверка: `py --version`.
2. Получите код. Репозиторий приватный, поэтому есть два способа:
   - на GitHub выберите **Code → Download ZIP** и распакуйте архив;
   - или установите [Git for Windows](https://git-scm.com/download/win) и выполните
     `git clone https://github.com/snail9847-coder/wewln-phonecaller.git` — Git попросит войти в GitHub.
3. Откройте PowerShell в папке проекта и выполните:

```powershell
py -3.12 -m venv .venv                     # или py -3.13 / py -3.14
.venv\Scripts\python.exe -m pip install -e ".[dev]"
Copy-Item .env.example .env                # затем при желании отредактируйте .env
.venv\Scripts\python.exe -m wewln_phonecaller check-config
.venv\Scripts\python.exe -m wewln_phonecaller serve
```

Проверка из второго окна PowerShell:

```powershell
Invoke-RestMethod http://127.0.0.1:8787/health
Invoke-RestMethod http://127.0.0.1:8787/ready | ConvertTo-Json -Depth 5
```

Сервер останавливается сочетанием `Ctrl+C`. Активировать виртуальное окружение
(`Activate.ps1`) не нужно — команды вызывают `.venv\Scripts\python.exe` напрямую, поэтому
политика выполнения скриптов PowerShell не мешает. Данные и логи хранятся в папке `data\`
рядом с местом запуска.

На Linux всё так же: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -e ".[dev]"`.

## Команды

| Команда | Что делает | Коды выхода |
| --- | --- | --- |
| `python -m wewln_phonecaller check-config` | проверка настроек, вывод без секретов | 0 — ок, 2 — ошибка настроек |
| `python -m wewln_phonecaller init-db` | создание или обновление БД | 0, 1 — ошибка БД, 2 |
| `python -m wewln_phonecaller serve [--host H] [--port P]` | локальный HTTP API | 0, 1, 2 |
| `python -m wewln_phonecaller --env-file путь …` | другой файл настроек (`""` — без файла) | — |

После установки доступна и короткая форма — `wewln` (в Windows: `.venv\Scripts\wewln.exe`).

## HTTP API

| Метод и путь | Доступ | Ответ |
| --- | --- | --- |
| `GET /health` | открыт | 200, если процесс жив |
| `GET /ready` | открыт | 200 или 503: БД, папка данных, Notion, телефония, гейт звонков |
| `GET /api/v1/info` | `Authorization: Bearer <WEWLN_API_TOKEN>` | версия и настройки без секретов |

Ошибки возвращаются в одном формате:
`{"error": {"code": "...", "message": "...", "request_id": "..."}}`. Если `WEWLN_API_TOKEN`
не задан, защищённые эндпоинты закрыты (код `auth_not_configured`).

## Тесты и проверки

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m ruff format --check .
```

GitHub Actions выполняет те же проверки на `ubuntu-latest` и `windows-latest` с Python 3.12,
3.13 и 3.14; результаты — на вкладке **Actions**. Подробнее — в [docs/TESTING.md](docs/TESTING.md).

## Что бесплатно, а что нет

| Часть | Решение | Стоимость |
| --- | --- | --- |
| Backend, БД, логи, тесты | Python, aiohttp, pydantic, SQLite, pytest, ruff | бесплатно, открытый код |
| CI | GitHub Actions | приватный репозиторий расходует бесплатную месячную квоту минут; минуты Windows дороже Linux |
| Распознавание речи (фаза 5) | faster-whisper, whisper.cpp, Vosk или sherpa-onnx — локально | бесплатно; нужно железо |
| Языковая модель (фаза 5) | Ollama и открытые модели — локально | бесплатно; лицензии моделей разные; нужно железо |
| Синтез речи (фаза 5) | Piper, RHVoice, sherpa-onnx; Silero — после проверки лицензии | ПО бесплатное; у голосов свои лицензии |
| АТС (фаза 4) | Asterisk в WSL2 или Docker | бесплатно, открытый код |
| Звонок своему софтфону через свою АТС | SIP внутри своей сети | бесплатно, но это не звонок на внешний номер |
| Звонки на мобильные и городские номера | SIP-провайдер или существующий SIP-аккаунт с выходом в телефонную сеть | **платно** (поминутно); пробный баланс бывает, но он мал и ограничен |

Бесплатных звонков на реальные мобильные и городские номера этот проект не обещает.
Подробности и что ещё нужно проверить (в том числе звонки на российские номера +7) — в плане.
