# wewln-phonecaller

Исходящие голосовые звонки с ИИ на русском языке. Управление — из Notion или без него,
запуск — на Windows 10/11. По умолчанию работает только симуляция: реальные звонки
заблокированы, пока владелец явно их не разрешит.

> **Статус: фаза 3 — Notion как пульт управления.** Готовы backend (настройки, SQLite, логи
> с маскировкой номеров, `/health` и `/ready`), кампании, контакты, список «Не звонить»,
> задания на звонки с симуляцией и двусторонняя синхронизация с Notion. Самих звонков
> (реальных разговоров), распознавания и синтеза речи и LLM пока **нет**: `simulate` только
> отмечает задания выполненными. Следующие фазы — в [плане](IMPLEMENTATION_PLAN.md).

## Что уже работает

- `check-config` проверяет настройки и печатает их без секретов. Заодно показывает, почему
  реальные звонки заблокированы.
- `init-db` создаёт или обновляет базу SQLite (журнал WAL, миграции в транзакциях).
- `serve` поднимает локальный HTTP API на `127.0.0.1:8787`: открытые `/health` и `/ready`,
  остальное — только с токеном (см. «HTTP API»).
- Логи в формате JSON или текстом — в консоль и в файл с ротацией. У каждого запроса свой
  `request_id`; номера телефонов и токены маскируются (`+79*******67`).
- Журнал аудита в SQLite фиксирует запуск и остановку сервера, создание и остановку кампаний,
  импорт контактов, изменения списка «Не звонить» и отмену заданий; номера в нём маскируются.
- Гейт реальных звонков. В этой версии он закрыт при любых настройках: есть только провайдер `mock`.
- Кампании, контакты (импорт CSV), задания на звонки и список «Не звонить» в SQLite — без Notion
  через команды `wewln`. Одно задание на пару «кампания + контакт», запрет звонков всегда сильнее.
- Notion (по желанию): четыре базы создаются командой `wewln notion bootstrap`, `wewln serve`
  синхронизирует их каждую минуту — кампании и контакты из Notion, статусы заданий и результаты
  обратно. Без дублей при повторах, с обработкой ошибок и лимитов Notion API. Токен хранится
  в Диспетчере учётных данных Windows. Пошагово — в [docs/NOTION.md](docs/NOTION.md).
- Остановка кампании и «Не звонить» работают и без связи с Notion.

## Принципы

- **Бесплатный стек.** Только бесплатные библиотеки с открытым кодом и локальные модели, без
  обязательных платных API. Платные сервисы (например, минуты телефонной сети) подключаются
  только по желанию владельца.
- **Русский язык обязателен.** Язык по умолчанию — `ru-RU`. Список языков расширяемый.
- **Windows прежде всего**, без зависимостей от macOS.
- **Notion — пульт управления, но не обязательная часть.** Backend работает и без Notion.
- **Безопасность по умолчанию.** Режим `simulation`, kill switch, отказ запускаться
  с опасными или неполными настройками.

## Установка и запуск на Windows 10/11

1. Установите Python 3.12, 3.13 или 3.14 (64-bit) с [python.org](https://www.python.org/downloads/windows/).
   В установщике отметьте «Add python.exe to PATH». Проверка: `py --version`.
2. Получите код одним из способов:
   - на странице репозитория на GitHub выберите **Code → Download ZIP** и распакуйте архив;
   - или установите [Git for Windows](https://git-scm.com/download/win) и выполните
     `git clone https://github.com/snail9847-coder/wewln-phonecaller.git`. Если у репозитория
     закрытый доступ, Git попросит войти в GitHub.
3. Откройте PowerShell в папке проекта и выполните:

```powershell
py -3.12 -m venv .venv                     # или py -3.13 / py -3.14
.venv\Scripts\python.exe -m pip install -e ".[dev]"
Copy-Item .env.example .env                # затем при желании отредактируйте .env
.venv\Scripts\python.exe -m wewln_phonecaller check-config
.venv\Scripts\python.exe -m wewln_phonecaller serve
```

Проверка из второго окна PowerShell:

```powershell
Invoke-RestMethod http://127.0.0.1:8787/health
Invoke-RestMethod http://127.0.0.1:8787/ready | ConvertTo-Json -Depth 5
```

Сервер останавливается сочетанием `Ctrl+C`. Активировать виртуальное окружение
(`Activate.ps1`) не нужно — команды вызывают `.venv\Scripts\python.exe` напрямую, поэтому
политика выполнения скриптов PowerShell не мешает. Данные и логи хранятся в папке `data\`
рядом с местом запуска.

На Linux всё так же: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -e ".[dev]"`.

Что дальше:

- подключить Notion — пошагово в [docs/NOTION.md](docs/NOTION.md);
- попробовать без аккаунта Notion — `wewln notion mock-server --demo` (там же, раздел
  «Попробовать без аккаунта Notion»);
- работать совсем без Notion — локальные кампании и импорт контактов из CSV (раздел
  «Работа без Notion» там же).

## Команды

Полная форма — `python -m wewln_phonecaller …`, короткая — `wewln …` (в Windows:
`.venv\Scripts\wewln.exe`). Коды выхода: 0 — успех, 1 — ошибка выполнения, 2 — ошибка настроек.

| Команда | Что делает |
| --- | --- |
| `check-config` | проверка настроек, вывод без секретов |
| `init-db` | создание или обновление БД |
| `serve [--host H] [--port P]` | локальный HTTP API и фоновая синхронизация с Notion |
| `notion token set` · `status` · `delete` | токен Notion в Диспетчере учётных данных Windows |
| `notion bootstrap --parent <ссылка> [--write-env]` | создать или найти четыре базы под страницей |
| `notion check [--repair]` | проверить токен и структуру баз, добавить недостающие свойства |
| `notion sync` · `notion status` | один цикл синхронизации сейчас · последние циклы |
| `notion mock-server [--demo]` | имитация Notion API для пробы без аккаунта |
| `campaign create` · `list` · `start` · `pause` · `stop` | локальные кампании; `stop` — для любой кампании |
| `contacts import <файл.csv> [--campaign N]` · `contacts list` | контакты (номера в выводе маскируются) |
| `jobs list` | задания на звонки со статусами и причинами |
| `dnc add` · `remove` · `list` | список «Не звонить» |
| `simulate [--campaign N]` | выполнить задания в очереди без реальных звонков |
| `--env-file путь …` | другой файл настроек (`""` — без файла) |

Подробности о Notion, CSV и статусах — в [docs/NOTION.md](docs/NOTION.md).

## HTTP API

| Метод и путь | Доступ | Ответ |
| --- | --- | --- |
| `GET /health` | открыт | 200, если процесс жив |
| `GET /ready` | открыт | 200 или 503: БД, папка данных, Notion, телефония, гейт звонков |
| `GET /api/v1/info` | `Authorization: Bearer <WEWLN_API_TOKEN>` | версия и настройки без секретов |
| `GET /api/v1/notion/status` | токен | состояние синхронизации и последние циклы |
| `POST /api/v1/notion/sync` | токен | цикл синхронизации сейчас |
| `GET /api/v1/campaigns` | токен | кампании со статусами и заданиями |
| `POST /api/v1/campaigns/{id}/stop` | токен | остановить кампанию (`{"reason": "..."}`) |
| `POST /api/v1/dnc` | токен | номер в «Не звонить» (`{"phone": "...", "reason": "..."}`) |

Ошибки возвращаются в одном формате:
`{"error": {"code": "...", "message": "...", "request_id": "..."}}`. Если `WEWLN_API_TOKEN`
не задан, защищённые эндпоинты закрыты (код `auth_not_configured`).

## Тесты и проверки

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m ruff format --check .
```

GitHub Actions выполняет те же проверки на `ubuntu-latest` и `windows-latest` с Python 3.12,
3.13 и 3.14; результаты — на вкладке **Actions**. Подробнее — в [docs/TESTING.md](docs/TESTING.md).

## Что бесплатно, а что нет

| Часть | Решение | Стоимость |
| --- | --- | --- |
| Backend, БД, логи, тесты | Python, aiohttp, pydantic, SQLite, phonenumbers, keyring, pytest, ruff | бесплатно, открытый код |
| Notion | официальный REST API, своё внутреннее подключение | API бесплатен на всех тарифах; в бесплатном пространстве с несколькими участниками — лимит 1000 блоков (см. [docs/NOTION.md](docs/NOTION.md)) |
| CI | GitHub Actions | для публичного репозитория стандартные раннеры бесплатны; для приватного расходуется месячная квота минут, минуты Windows дороже Linux |
| Распознавание речи (фаза 5) | faster-whisper, whisper.cpp, Vosk или sherpa-onnx — локально | бесплатно; нужно железо |
| Языковая модель (фаза 5) | Ollama и открытые модели — локально | бесплатно; лицензии моделей разные; нужно железо |
| Синтез речи (фаза 5) | Piper, RHVoice, sherpa-onnx; Silero — после проверки лицензии | ПО бесплатное; у голосов свои лицензии |
| АТС (фаза 4) | Asterisk в WSL2 или Docker | бесплатно, открытый код |
| Звонок своему софтфону через свою АТС | SIP внутри своей сети | бесплатно, но это не звонок на внешний номер |
| Звонки на мобильные и городские номера | SIP-провайдер или существующий SIP-аккаунт с выходом в телефонную сеть | **платно** (поминутно); пробный баланс бывает, но он мал и ограничен |

Бесплатных звонков на реальные мобильные и городские номера этот проект не обещает.
Подробности и что ещё нужно проверить (в том числе звонки на российские номера +7) — в плане.
