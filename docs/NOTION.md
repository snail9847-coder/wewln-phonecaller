# Notion: подключение и синхронизация

Notion — необязательный пульт управления. В нём вы ведёте кампании и контакты, запускаете
и останавливаете кампании, а wewln показывает там задания на звонки, их статусы и результаты.
Без Notion всё то же самое делается командами `wewln` (раздел «Работа без Notion»).

В этой версии звонков нет: работает только симуляция (`wewln simulate`), реальный номер не
набирается ни при каких настройках.

Ниже `wewln` — это `.venv\Scripts\wewln.exe` в папке проекта (или
`.venv\Scripts\python.exe -m wewln_phonecaller`). Команды даны для PowerShell в Windows 10/11.

## Как это устроено

- wewln сам опрашивает Notion (polling): `wewln serve` — раз в `WEWLN_NOTION_SYNC_INTERVAL`
  секунд (по умолчанию 60), `wewln notion sync` — один цикл сразу. Вебхуки Notion не
  используются: им нужен публичный HTTPS-адрес, а wewln работает на вашем компьютере.
- Источник истины о заданиях и звонках — локальная база SQLite. Notion получает её копию,
  поэтому остановка кампании и список «Не звонить» работают и тогда, когда Notion недоступен.
- Из Notion wewln читает только страницы, к которым вы дали доступ своему подключению.

## Четыре базы данных

`wewln notion bootstrap` создаёт их сам (шаг 6). Свойства находятся **по имени** — не
переименовывайте их и не меняйте их тип. Свои свойства добавлять можно, wewln их не трогает.
Главное свойство (заголовок) переименовать можно.

### «Кампании (wewln)»

| Свойство | Тип | Кто заполняет | Значение |
| --- | --- | --- | --- |
| Название | заголовок | вы | имя кампании |
| Статус | select | вы; wewln — при остановке | Черновик, Запущена, Пауза, Остановлена, Завершена |
| Сценарий | текст | вы | текст сценария разговора (понадобится голосовому движку, фаза 5) |
| Язык | select | вы | `ru-RU`; пусто — `WEWLN_DEFAULT_LANGUAGE` |
| Макс. попыток | число | вы | целое от 1 до 5; пока только проверяется, повторы звонков появятся в фазе 6 |
| Сводка | текст | wewln | число заданий по статусам и пометка о режиме симуляции |
| Ошибка | текст | wewln | что мешает кампании (неизвестный статус, неподдерживаемый язык, попытка перезапуска) |

### «Контакты (wewln)»

| Свойство | Тип | Кто заполняет | Значение |
| --- | --- | --- | --- |
| Имя | заголовок | вы | имя контакта |
| Телефон | телефон | вы | лучше в международном формате: `+994 50 123 45 67`, `+7 912 345-67-89` |
| Не звонить | флажок | вы; wewln — по локальному списку | на этот номер никогда не звонить |
| Причина запрета | текст | вы; wewln, если пусто | почему нельзя звонить |
| Кампании | связь → «Кампании (wewln)» | вы | в каких кампаниях участвует контакт |
| Ошибка | текст | wewln | проблема с номером: не указан, не распознан, нет кода страны |

### «Задания на звонки (wewln)» — ведёт wewln

| Свойство | Тип | Значение |
| --- | --- | --- |
| Задание | заголовок | «Контакт — Кампания» |
| Кампания, Контакт | связи | к какой кампании и какому контакту относится задание |
| Статус | select | В очереди, Заблокировано, Выполняется, Выполнено, Ошибка, Отменено |
| Причина | текст | почему задание заблокировано или отменено |
| Попытки | число | сколько попыток сделано |
| Ключ | текст | ключ идемпотентности, защита от дублей — **не меняйте** |
| Обновлено | дата | когда статус изменился в wewln |
| Симуляция | флажок | задание создано в режиме симуляции |

### «Результаты звонков (wewln)» — ведёт wewln

| Свойство | Тип | Значение |
| --- | --- | --- |
| Результат | заголовок | «Исход — Контакт» |
| Задание, Кампания, Контакт | связи | откуда результат |
| Исход | select | Симуляция, Ответ, Нет ответа, Занято, Ошибка, Отказ |
| Начало | дата | время попытки |
| Длительность, с | число | длительность разговора |
| Итог | текст | краткий итог; у симуляции — «Симуляция: реальный звонок не выполнялся» |
| Ключ | текст | ключ идемпотентности — **не меняйте** |
| Симуляция | флажок | результат симуляции, а не реального звонка |

## Подключение: пошагово

Нужны установленный проект (см. [README](../README.md)) и права владельца рабочего
пространства Notion (Workspace Owner) — только он может создать внутреннее подключение.

1. **Страница для баз.** Создайте в Notion обычную страницу, например «wewln». Под ней
   появятся четыре базы.
2. **Внутреннее подключение.** Откройте портал разработчика
   <https://app.notion.com/developers/connections>, в разделе **Build** выберите
   **Internal connections** → **Create a new connection**. Введите имя (например, `wewln`)
   и выберите своё рабочее пространство.
3. **Возможности и токен.** На вкладке **Configuration** включите возможности
   **Read content**, **Update content** и **Insert content** (сведения о пользователях не
   нужны). Там же скопируйте **API token** — он начинается с `ntn_`.
4. **Доступ к странице.** Откройте страницу «wewln» → меню **•••** справа вверху →
   **Connections** → **+ Add connection** → выберите своё подключение и подтвердите. Доступ
   наследуют все вложенные страницы и базы. То же можно сделать в портале разработчика:
   вкладка **Content access** → **Edit access**.
5. **Сохраните токен** в Диспетчере учётных данных Windows:

   ```powershell
   .venv\Scripts\wewln.exe notion token set
   .venv\Scripts\wewln.exe notion token status
   ```

   Вставьте токен (Ctrl+V или правой кнопкой мыши; символы не отображаются) и нажмите Enter.
   Токен хранится в разделе «Учётные данные Windows» под именем `wewln-phonecaller` и не
   попадает ни в файлы проекта, ни в логи. Другие варианты — в разделе «Где хранить токен».
6. **Создайте базы.** Скопируйте ссылку на страницу (**•••** → **Copy link**) и выполните:

   ```powershell
   .venv\Scripts\wewln.exe notion bootstrap --parent "ссылка-на-страницу" --write-env
   ```

   wewln создаст четыре базы и запишет их ID в `.env` вместе с `WEWLN_NOTION_ENABLED=true`.
   Без `--write-env` он только напечатает эти строки. Команду можно повторять: существующие
   базы находятся по названию, отсутствующие свойства и варианты добавляются, дублей нет.
7. **Проверьте подключение:**

   ```powershell
   .venv\Scripts\wewln.exe notion check
   ```

   В конце должно быть `Notion is ready for the sync.` Если чего-то не хватает, команда назовёт
   проблему (см. «Если что-то не работает»).
8. **Заполните данные в Notion.** Создайте кампанию (Название, Статус «Черновик»), затем
   контакты: Имя, Телефон и связь «Кампании». Когда всё готово, поставьте кампании статус
   «Запущена».
9. **Синхронизируйте:** `wewln notion sync` (один цикл) или `wewln serve` (сервер синхронизирует
   сам каждые 60 секунд). В базе «Задания на звонки (wewln)» появится по заданию на каждый
   контакт кампании — «В очереди» или «Заблокировано» с причиной.
10. **Симуляция:** `wewln simulate` выполняет задания «В очереди» без реальных звонков.
    Следующая синхронизация отметит их «Выполнено», создаст страницы в «Результаты звонков
    (wewln)» и обновит «Сводку» кампании.

Состояние синхронизации: `wewln notion status` (последние циклы), `GET /ready`
(раздел `checks.notion`) и `GET /api/v1/notion/status`.

## Где хранить токен

wewln ищет токен в таком порядке:

1. переменная окружения `WEWLN_NOTION_TOKEN` (на один сеанс PowerShell:
   `$env:WEWLN_NOTION_TOKEN = "ntn_..."`);
2. файл `.env` (строка `WEWLN_NOTION_TOKEN=...`) — проще, но токен лежит открытым текстом;
   `.env` исключён из git, никому его не отправляйте;
3. Диспетчер учётных данных Windows (`wewln notion token set`) — **рекомендуется**.

`wewln notion token status` и `check-config` показывают только источник (`set (credential
store)`), но не значение. Удалить сохранённый токен: `wewln notion token delete`. Если токен
мог утечь, обновите его (refresh) на вкладке **Configuration** подключения и сохраните новый.

Вместо внутреннего подключения можно использовать личный токен (personal access token), он
создаётся в том же портале разработчика. Такой токен действует от вашего имени, с вашими правами,
и истекает не позже чем через год. Для постоянной работы удобнее внутреннее подключение.

## Как работают статусы

- **Статусы кампании** задаёте вы в Notion. «Черновик» и «Пауза» — задания не выполняются
  (на паузе они сохраняются). «Запущена» — wewln планирует задания для всех контактов кампании.
  «Остановлена» и «Завершена» — окончательные: открытые задания становятся «Отменено».
- **Остановленную или завершённую кампанию нельзя запустить снова.** Если поставить ей
  «Запущена», wewln вернёт прежний статус и объяснит причину в свойстве «Ошибка». Для нового
  обзвона создайте новую кампанию.
- **Остановка из wewln** работает и без Notion: `wewln campaign stop <id> --reason "почему"`
  или `POST /api/v1/campaigns/{id}/stop`. Ближайшая синхронизация поставит в Notion
  «Остановлена». ID кампании показывает `wewln campaign list`.
- **Статусы заданий ведёт wewln.** Изменения статуса, причины или попыток в Notion
  откатываются при следующей синхронизации. Исключение — **«Отменено»**: если поставить его
  вручную, wewln принимает отмену и этот контакт в кампании больше не вызывается. Удалить
  страницу задания — тоже отмена; заново она не создаётся.
- **Контакт убран из кампании** (снята связь «Кампании») — задание «Отменено». Если вернуть
  контакт, пока кампания запущена, задание снова встанет в очередь. Удалённый контакт — задание
  «Отменено» с причиной «Контакт удалён или недоступен».
- **Страница кампании удалена или перенесена** — кампания встаёт на паузу локально, причина
  видна в `wewln campaign list`.

## «Не звонить»

- Флажок «Не звонить» в Notion блокирует задания с этим номером: «Заблокировано», причина
  «Номер в списке «Не звонить»».
- Локальный список: `wewln dnc add <номер> --reason "почему"` или `POST /api/v1/dnc`. Он действует
  на все кампании и все контакты с этим номером. Ближайшая синхронизация поставит флажок
  в Notion и, если причина не заполнена, напишет «Добавлено в wewln».
- Запрет всегда сильнее: если номер запрещён хотя бы в одном месте, звонка не будет.
- Снять запрет: сначала `wewln dnc remove <номер>` (`--all` удаляет все локальные записи),
  затем снимите флажок в Notion. Если снять флажок раньше, wewln поставит его снова: номер ещё
  в локальном списке. `wewln dnc list` показывает, откуда запрет.

## Защита от дублей

- У каждого задания и результата есть «Ключ», например `wewln:job:<кампания>:<контакт>` из ID
  страниц Notion. На пару «кампания + контакт» бывает ровно одно задание, сколько бы раз ни
  запускалась синхронизация.
- Перед созданием страницы wewln ищет в Notion задания кампании с тем же ключом. Если Notion
  не подтвердил создание (таймаут, ошибка 5xx), запрос не повторяется вслепую: пять минут
  wewln ищет страницу по ключу и только потом создаёт её снова.
- Если локальная база потеряна или восстановлена из копии, wewln находит существующие страницы
  по ключу и принимает их состояние: выполненное и отменённое не вызывается повторно, а задание
  в статусе «Выполняется» становится «Ошибка» с просьбой проверить вручную.
- Копии страниц с одинаковым ключом (например, после дублирования вручную) wewln не
  использует: берёт самую старую и сообщает о лишних в результате синхронизации.
- Одновременно работает только одна синхронизация (блокировка в SQLite, общая для всех
  процессов wewln с этой базой).

## Работа без Notion

По умолчанию `WEWLN_NOTION_ENABLED=false`, и всё работает локально:

```powershell
.venv\Scripts\wewln.exe campaign create "Весна" --script "Здравствуйте! ..."
.venv\Scripts\wewln.exe contacts import contacts.csv --campaign 1
.venv\Scripts\wewln.exe campaign start 1
.venv\Scripts\wewln.exe jobs list
.venv\Scripts\wewln.exe simulate --campaign 1
.venv\Scripts\wewln.exe campaign stop 1 --reason "Готово"
```

CSV для импорта: первая строка — названия столбцов `name`/`имя`, `phone`/`телефон`,
`dnc`/`не звонить` (значения `да`, `yes`, `1`, `x`). Разделитель — запятая, точка с запятой
или табуляция; кодировка UTF-8 или Windows-1251 (так сохраняет Excel). Строки с неверным
номером не импортируются, `contacts import` называет их номера строк.

Если Notion включён, но недоступен (нет интернета, сбой Notion, неверный токен), `wewln serve`
продолжает работать: `/ready` отвечает 200, а в `checks.notion` стоит `degraded` и код ошибки.
При интервале 60 секунд повторы идут через 60, 120, 240, 480 и далее каждые 900 секунд
(не раньше, чем разрешает `Retry-After` от Notion).
Остановка и «Не звонить» срабатывают локально сразу, а в Notion попадают после восстановления
связи.

## Попробовать без аккаунта Notion

В проекте есть имитация Notion API (данные только в памяти, в интернет ничего не уходит):

```powershell
# окно 1
.venv\Scripts\wewln.exe notion mock-server --demo
```

Команда печатает строки `$env:...` — выполните их во втором окне PowerShell в папке проекта,
затем:

```powershell
# окно 2
.venv\Scripts\wewln.exe notion sync
.venv\Scripts\wewln.exe simulate
.venv\Scripts\wewln.exe notion sync
.venv\Scripts\wewln.exe jobs list
```

В демо-кампании три контакта: один в очереди, один с флажком «Не звонить» и один с неверным
номером. Номера демо-контактов зарезервированы регулятором Австралии для художественных
произведений и никому не принадлежат. Без `--demo` имитация пустая и подсказывает команду
`notion bootstrap`.

## HTTP API

Все запросы — с заголовком `Authorization: Bearer <WEWLN_API_TOKEN>`.

| Метод и путь | Что делает |
| --- | --- |
| `GET /api/v1/notion/status` | состояние фоновой синхронизации и последние циклы |
| `POST /api/v1/notion/sync` | выполнить цикл сейчас; 409, если Notion выключен или цикл уже идёт |
| `GET /api/v1/campaigns` | кампании со статусами и числом заданий |
| `POST /api/v1/campaigns/{id}/stop` | остановить кампанию; тело `{"reason": "..."}` необязательно |
| `POST /api/v1/dnc` | добавить номер в «Не звонить»: `{"phone": "+994...", "reason": "..."}` |

Пример для PowerShell:

```powershell
$h = @{ Authorization = "Bearer $env:WEWLN_API_TOKEN" }
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8787/api/v1/campaigns/1/stop `
  -Headers $h -ContentType "application/json; charset=utf-8" -Body '{"reason": "Хватит"}'
```

## Ограничения Notion API и что с ними делает wewln

| Ограничение | Что делает wewln |
| --- | --- |
| Лимит запросов на подключение: 180 в минуту на тарифах Free и Plus, 600 — на Business и Enterprise; запросы к базам — около 3 в секунду; есть общий лимит рабочего пространства | не больше 2,5 запроса в секунду (`WEWLN_NOTION_MAX_RPS`); на ответ 429 ждёт `Retry-After`; если ждать дольше минуты, завершает цикл и повторяет позже |
| Ответ на запрос к базе — не больше 100 страниц, всего не больше 10 000 результатов на запрос | читает все страницы постранично и делит выборку по времени создания; если список всё равно неполный, удалённые страницы в этом цикле не ищет и сообщает об этом |
| Страница показывает не больше 25 связей | остальные связи дочитывает отдельным запросом |
| Текст: не больше 2000 символов в одном фрагменте, 100 фрагментов | длинный текст делится на фрагменты (до 200 000 символов) |
| Ошибка 5xx при записи не значит, что запись не сохранилась | ключ идемпотентности и поиск перед повторным созданием (см. «Защита от дублей») |
| Вебхукам нужен публичный HTTPS-адрес | опрос раз в минуту: изменения в Notion видны с задержкой до интервала синхронизации |
| Удаление страницы видно только при полном просмотре базы | wewln каждый цикл читает кампании и контакты целиком |
| Бесплатное рабочее пространство с несколькими участниками: не больше 1000 блоков за всё время, каждая страница — блок | создание заданий и результатов остановится с ошибкой 403 `restricted_resource`; на платных тарифах и в бесплатном пространстве с одним участником блоков без ограничений |
| В новых версиях API у базы может быть несколько источников данных | wewln работает только с базами, у которых один источник данных |

Версия API зафиксирована: `Notion-Version: 2026-03-11`.

## Если что-то не работает

| Сообщение | Что сделать |
| --- | --- |
| `Notion token is not set` | шаг 5 или переменная `WEWLN_NOTION_TOKEN` |
| `Notion API error 401 unauthorized` | токен неверный или отозван: скопируйте его заново на вкладке **Configuration** |
| `... was not found or is not shared with the connection` | шаг 4: дайте подключению доступ к странице с базами |
| `the connection lacks a capability` | шаг 3: включите Read, Update и Insert content |
| `missing property «...»` | `wewln notion check --repair` добавит недостающее |
| `property «...» must be ..., found ...` | верните свойству прежний тип или переименуйте его, тогда `--repair` создаст новое; типы wewln не меняет никогда |
| `the parent page contains 2 databases named «...»` | удалите или переименуйте лишнюю базу |
| `Notion did not confirm ...` | запустите команду ещё раз — дублей не будет |
| `rate_limited` | подождите; при частых повторах уменьшите `WEWLN_NOTION_MAX_RPS` |
| `another Notion sync is running` | уже работает другой процесс wewln (например, `serve`); после сбоя блокировка снимается сама через 5 минут |
| «Номер без кода страны» в свойстве «Ошибка» контакта | укажите номер с `+7`/`+994` или задайте `WEWLN_DEFAULT_PHONE_REGION` |
