# Провайдеры телефонии

Исследование от 3 ноября 2026 года. Цены и условия меняются: перед оплатой проверьте их на сайте
провайдера по ссылкам ниже. Этот документ не юридическая консультация.

## Главное

- Бесплатно позвонить на любые внешние номера +7 и +994 нельзя. Программы могут стоить $0, но
  минуты в обычную телефонную сеть платные у всех найденных провайдеров.
- Пробные периоды облачных провайдеров разрешают звонить только на ваш собственный
  подтверждённый номер.
- Главный риск — закон, особенно в России: автоматические звонки без согласия абонента
  запрещены (см. [Закон](#закон)).

## Что поддерживает wewln

| Провайдер в wewln | Что это | Реальные звонки |
| --- | --- | --- |
| `mock` (по умолчанию) | симуляция внутри программы, ничего никуда не звонит | нет |
| `asterisk` | ваш Asterisk через ARI; к телефонам — через SIP-транк любого провайдера | только тестовый звонок на один номер по разрешению оператора (`wewln calls permit`) |

Облачные API (Twilio, Telnyx, Vonage и другие) в этой версии не подключаются напрямую. Их можно
использовать как обычный SIP-транк для Asterisk, если провайдер это поддерживает. Вебхуки
`/api/v1/telephony/events` принимают события только в формате wewln с подписью wewln
(см. [SECURITY.md](../SECURITY.md)), а не в формате конкретного провайдера.

## Рекомендуемая схема

**ПК с Windows → WSL2 (Ubuntu) → Asterisk 22 LTS → любой SIP-провайдер.** Для начала подойдёт
Zadarma: у неё самые низкие найденные цены на +994. Установка — в [ASTERISK.md](ASTERISK.md).

Почему так:

- программы стоят $0, платить нужно только за минуты;
- провайдера можно сменить в конфигурации Asterisk, код wewln менять не нужно;
- голос будет обрабатываться на вашем ПК (фаза 5);
- Asterisk работает отдельной программой, поэтому его лицензия GPL не смешивается с кодом
  wewln.

Готовые Python-библиотеки для SIP слабее: например, pyVoIP 2.0 всё ещё в альфа-версии и под
лицензией GPLv3 ([PyPI](https://pypi.org/project/pyVoIP/)).

## Что бесплатно

- **Asterisk** — бесплатная АТС с открытым кодом. Версия 22 LTS полностью поддерживается
  до 16.10.2028 ([версии Asterisk](https://docs.asterisk.org/About-the-Project/Asterisk-Versions/)).
  Официально ставится только на Linux и Solaris
  ([установка](https://docs.asterisk.org/Getting-Started/Installing-Asterisk/)), поэтому на
  Windows — через WSL2: Windows 10 версии 2004 и новее или Windows 11
  ([WSL](https://learn.microsoft.com/en-us/windows/wsl/install)). В Ubuntu 26.04 есть готовый
  пакет Asterisk 22.5.2 ([пакет](https://packages.ubuntu.com/resolute/asterisk)).
- **MicroSIP** — бесплатный софтфон для Windows с открытым кодом, лицензия GPL
  ([microsip.org](https://www.microsip.org/)). Подходит для проверки без телефонной сети
  ([ASTERISK.md](ASTERISK.md), шаг 6).
- **Zadarma**: бесплатны регистрация, эхо-тест 4444, внутренний SIP-номер и звонки между
  SIP-номерами внутри сети. Исходящие звонки в телефонную сеть платные
  ([FAQ](https://zadarma.com/en/support/faq/zadarma/how-much-does-it-cost/)).

## Как выбрать провайдера

- Есть SIP-транк с регистрацией по логину и паролю или с доступом по IP: это нужно Asterisk.
- Разрешены нужные направления (+994, +7) и известна цена за минуту; посекундная тарификация
  дешевле для коротких звонков.
- Предоплата без автоматического пополнения и лимит расходов: ошибка в настройках не обойдётся
  дороже баланса.
- Правила провайдера разрешают ваш сценарий. Например, правила Zadarma запрещают массовые
  коммерческие сообщения и автодозвон, запрещённый законом
  ([условия](https://zadarma.com/en/legal/terms-of-use/)).
- Caller ID: провайдер может показывать только ваш номер у него. Подмена номера в wewln не
  поддерживается и не появится.
- Провайдер принимает кодек G.711 (alaw или ulaw): пример `deploy/asterisk/pjsip.conf`
  разрешает только его.

Подключение к Asterisk — [ASTERISK.md](ASTERISK.md), шаг 7.

## Закон

### Россия

- Массовые и автоматические звонки разрешены только с предварительного согласия абонента;
  доказывать согласие должен заказчик. Массовые звонки по инициативе заказчика — только по
  договору с оператором абонента
  ([ст. 44.1 закона «О связи»](https://www.zakonrf.info/zosvyazi/44.1-1/)).
- С 1 сентября 2025 года операторы сами выявляют такие звонки и могут блокировать их
  ([КонсультантПлюс](https://www.consultant.ru/legalnews/30562/)).
- Автодозвон с рекламой запрещён
  ([38-ФЗ, ст. 18](https://legalacts.ru/doc/federalnyi-zakon-ot-13032006-n-38-fz-o/glava-2/statja-18/)).
- По закону, подписанному 26.06.2026, абонент сможет запретить входящие звонки из-за рубежа
  ([РИА Новости](https://ria.ru/20260626/zvonki-2101343677.html)); звонки через иностранного
  провайдера могут блокироваться. Дата вступления закона в силу не найдена.

### Азербайджан

- Реклама абоненту — только с его согласия, записанного в договоре; отказаться можно
  в любой момент ([закон о рекламе](https://frameworks.e-qanun.az/36/f_36023.html)).
- Правила для нерекламных автоматических звонков не найдены.

### Вывод

Звонить только людям, которые дали согласие, небольшими объёмами и с предупреждением,
что говорит ИИ. Автоматический обзвон в Россию с домашнего ПК через иностранного провайдера почти
наверняка не вписывается в закон. Перед реальными кампаниями нужна консультация юриста.
