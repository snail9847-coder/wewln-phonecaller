# Архитектура

## Сейчас: фаза 2 (фундамент)

```text
cli.py ── check-config · init-db · serve
  │
  ├─ config.py ─────── Settings: переменные WEWLN_* и .env, проверка, SecretStr
  ├─ logging_setup.py ─ JSON или текст, request_id и call_id, маскировка (redact.py)
  ├─ storage/ ──────── SQLite: WAL, миграции, audit_log
  ├─ safety.py ─────── гейт реальных звонков
  ├─ telephony/ ────── реестр провайдеров (пока только mock)
  └─ api/app.py ────── aiohttp: /health, /ready, /api/v1/info
                       middleware: request_id → JSON-ошибки → проверка токена → обработчик
```

| Модуль | Ответственность |
| --- | --- |
| `config.py` | Загрузка и проверка настроек (pydantic-settings). Перекрёстные проверки: `production` только с фразой подтверждения, адрес не из loopback — только с токеном, Notion — только с токеном. Ошибки называют переменные, но не показывают значения |
| `errors.py` | Иерархия ошибок со стабильными кодами и HTTP-статусами: `config_invalid`, `storage_error` (503), `unauthorized` (401), `real_calls_blocked` (409) |
| `redact.py` | Маскировка номеров (первые и последние две цифры) и секретов. Даты и время не принимаются за номера |
| `logging_setup.py` | Форматтеры JSON и текста, контекст `request_id` и `call_id` через `contextvars`, маскировка всего, что попадает в лог, файл с ротацией в UTF-8 |
| `storage/db.py` | Короткие подключения к SQLite, режим WAL, миграции «только вперёд» (каждая в своей транзакции), проверка готовности без создания файла, журнал аудита |
| `safety.py` | `evaluate_real_calls()` возвращает решение и **все** причины блокировки |
| `telephony/` | `ProviderInfo` и реестр `PROVIDERS`. Флаг `places_real_calls` есть у каждого провайдера; у `mock` — `False` |
| `api/app.py` | HTTP API, `X-Request-ID` (своё значение принимается, только если оно безопасно), единый JSON-формат ошибок, Bearer-токен, проверки готовности |
| `cli.py` | Команды и коды выхода (0 — ок, 1 — ошибка выполнения, 2 — ошибка настроек), UTF-8 в консоли Windows |

### Запуск `serve`

1. Загрузка и проверка настроек. Если они неверны — выход с кодом 2, сервер не стартует.
2. Настройка логов. Значения секретов заранее передаются маскировщику.
3. Миграции БД. Ошибка — выход с кодом 1.
4. Запись `app.start` в журнал аудита вместе с решением гейта реальных звонков.
5. Запуск aiohttp на `WEWLN_HTTP_HOST:WEWLN_HTTP_PORT`. При штатной остановке — запись `app.stop`.

### Данные (схема версии 1)

- `schema_migrations(version, name, applied_at)` — применённые миграции.
- `audit_log(id, ts, actor, action, subject, details, request_id)` — журнал действий;
  `subject` и `details` записываются уже замаскированными.

Применённую миграцию не меняют — добавляют новую в `storage/migrations.py`.
`/ready` сообщает `schema_out_of_date`, если версия БД отстаёт от кода.

## Целевая архитектура (фазы 3–6)

```text
Notion (пульт, необязателен) ─┐      локальный источник (CLI, файлы) ─┐
  контакты, сценарии, кампании,│                                       │
  старт и стоп, статусы, итоги ▼                                       ▼
                     control/: единый интерфейс источника кампаний
                                  │
                     orchestrator/ ── safety/ (режим, kill switch, arm, согласие, DNC, часы, лимиты)
                                  │
                     telephony/ ── mock │ SIP через Asterisk (WSL2/Docker) │ другие адаптеры
                                  │ аудио и события звонка
                     voice/ ── STT ⇄ LLM ⇄ TTS (локально, русский язык), сценарий, история, итог
                                  │
                     storage/ ── SQLite: кампании, контакты, сценарии, звонки, реплики, итоги, аудит
```

- **Notion не обязателен.** Источник кампаний — интерфейс с двумя реализациями: Notion
  (официальный API) и локальная (CLI и файлы). Состояние звонков всегда хранится в SQLite,
  а Notion получает его копию.
- **Языки.** Реестр `SUPPORTED_LANGUAGES` в `config.py`. Для каждого языка позже задаются модель
  распознавания, голос синтеза, системные подсказки LLM и фразы отказа («не звоните мне»).
- **Телефония.** Новый провайдер регистрируется в `PROVIDERS`. Флаг `places_real_calls=True`
  сам по себе ничего не разрешает — нужен ещё весь гейт из `safety.py`.
- **Голос.** Интерфейсы STT, LLM и TTS с mock-реализациями для тестов; реальные движки —
  локальные и бесплатные (кандидаты — в плане, раздел 8).

## Особенности Windows

- Пути — только через `pathlib`. Все файлы читаются и пишутся в UTF-8; вывод в консоль
  переключается на UTF-8, чтобы русский текст не ломался.
- База часовых поясов в Windows берётся из пакета `tzdata`.
- Логи закрываются явно: Windows не даёт удалить открытый файл.
- Нет зависимостей от macOS и POSIX-сигналов. Asterisk под Windows не работает нативно —
  только в WSL2 или Docker (фаза 4).
