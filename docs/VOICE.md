# Голосовой движок (фаза 5)

Когда на звонок ответили, wewln ведёт разговор на русском языке. Распознавание речи (STT),
диалоговая модель (LLM) и синтез речи (TTS) работают **на вашем компьютере**: по умолчанию
ни звук, ни текст разговора никуда не отправляются. Движок включается настройкой
`WEWLN_VOICE_MODE=ai`; по умолчанию (`off`) на ответивший звонок проигрывается короткое
сообщение, как в фазе 4.

```text
телефон ◀─▶ провайдер ◀─SIP─▶ Asterisk (WSL2) ◀─AudioSocket: TCP, 8 кГц─▶ wewln (Windows)
                                                                         │
           ┌─────────────────────────────────────────────────────────────┘
           ▼
  детектор речи (конец реплики после паузы 0,7 с)
    → Vosk / faster-whisper: текст
    → Ollama (qwen3:4b): ответ потоком
    → Piper: каждое готовое предложение сразу озвучивается и отправляется в звонок
```

С провайдером `mock` звонков нет вообще: звук идёт в памяти, а «собеседника» играет
синтезированный голос (симуляция).

## Что проверено, а что нет

| Что | Как проверено |
| --- | --- |
| Логика разговора: детектор речи, конец реплики, перебивание, защита от эха, переспрашивание при тишине, отказ моделей, лимит реплик и длительности, «не звоните мне», аварийная остановка, расшифровки | автотесты с поддельными моделями (`tests/test_voice_*.py`) |
| Протокол AudioSocket, мост и externalMedia в ARI | автотесты с имитацией ARI и настоящим TCP-соединением (`tests/test_asterisk_voice.py`) |
| Настоящий Asterisk 20 и 22: AudioSocket, звук в обе стороны | CI, задание `live Asterisk (ARI)`: звонки на Local-каналы — Asterisk проигрывает запись, wewln её слышит и отвечает; эхо возвращает голос wewln |
| Обрыв звукового канала Asterisk 22.5.2 (ошибка AudioSocket, [ASTERISK.md](ASTERISK.md#требования)) | автотест с имитацией ARI: wewln подключает новый канал, разговор продолжается |
| Vosk и Piper на Ubuntu и Windows | CI, задание `voice models`: Piper говорит, Vosk распознаёт на 8 кГц, проходит разговор через движок, работает `wewln voice check` |
| Ollama | в Linux-песочнице с маленькой моделью `qwen3:0.6b`: работает, но отвечает слабо и повторяется. Рекомендуемая `qwen3:4b` **не проверялась** |
| Windows-ПК владельца, софтфон MicroSIP с голосом | **не проверено** |
| Реальный звонок на телефон | **не проверено**: нужен SIP-провайдер и отдельное разрешение владельца |

## Компоненты и лицензии

Все компоненты бесплатные. Ставятся только с разрешения владельца, потому что это установка
программ и загрузка моделей.

| Часть | По умолчанию | Другие варианты | Лицензия | Размер |
| --- | --- | --- | --- | --- |
| Распознавание | Vosk, модель `vosk-model-small-ru-0.22` | faster-whisper (`WEWLN_VOICE_STT=faster-whisper`), сервер whisper.cpp (`whisper-http`) | Vosk и модель — Apache 2.0 ([alphacephei.com](https://alphacephei.com/vosk/models)) | модель 45 МБ |
| Диалоговая модель | Ollama, `qwen3:4b` | любая модель Ollama; сервер с API OpenAI (`WEWLN_VOICE_LLM=openai`: llama.cpp, LM Studio) | Ollama — MIT; у моделей свои лицензии | `qwen3:4b` ≈ 2,5 ГБ |
| Синтез | Piper (`piper-tts`), голос `ru_RU-denis-medium` | другой голос Piper (`WEWLN_VOICE_TTS_MODEL`), HTTP-сервер Piper (`piper-http`) | `piper-tts` 1.3+ — GPL-3.0; у голосов свои лицензии (ниже) | голос 63 МБ |
| Python-пакеты | `pip install -e ".[voice]"`: vosk, piper-tts, onnxruntime, numpy | `.[whisper]` для faster-whisper | открытые | ≈ 200 МБ |

### Лицензии голосов Piper — важно для коммерческого использования

Набор записей голосов `denis` и `dmitri` выложен как CC0, у `irina` лицензия не указана,
`ruslan` — CC BY-NC-SA 4.0 (без коммерческого использования). Но все русские голоса Piper
дообучены из английской модели `lessac`, а набор данных lessac (Blizzard 2013) разрешён только
для исследований, без коммерческого использования
([лицензия](https://www.cstr.ed.ac.uk/projects/blizzard/2013/lessac_blizzard2013/license.html)).
Поэтому для коммерческих звонков голос Piper нужно сначала проверить у юриста или заменить
голосом с понятной лицензией (например, обученным с нуля на своих записях). Для тестов и
личного использования это не ограничение.

`piper-tts` с версии 1.3 распространяется под GPL-3.0. wewln не включает его в свой код,
а загружает как отдельный пакет; если вы будете распространять сборку wewln вместе с Piper,
учитывайте условия GPL.

## Установка на Windows

Все шаги — на вашем ПК и только с вашего согласия: это установка программ и загрузка около
110 МБ моделей (плюс ≈ 2,5 ГБ для `qwen3:4b`).

1. Пакеты голоса (в папке wewln, PowerShell):

   ```powershell
   .venv\Scripts\python.exe -m pip install -e ".[dev,voice]"
   ```

2. Модели распознавания и синтеза. Команда скачивает файлы только по HTTPS, проверяет размер
   и SHA-256 и кладёт их в `data\models`:

   ```powershell
   .venv\Scripts\wewln.exe voice download all
   ```

   Без интернета на этом ПК: скачайте файлы на другом компьютере (адреса, размеры и SHA-256
   печатает `wewln voice download --help`) и выполните
   `wewln voice download all --from <папка с файлами>`.

3. Диалоговая модель: установите Ollama для Windows с [ollama.com](https://ollama.com/download)
   и скачайте модель:

   ```powershell
   ollama pull qwen3:4b
   ```

   На слабом ПК можно взять модель меньше (`WEWLN_VOICE_LLM_MODEL=qwen3:1.7b`), но качество
   разговора падает: `qwen3:0.6b` в тестах отвечала невпопад и повторялась.

4. В `.env`:

   ```dotenv
   WEWLN_VOICE_MODE=ai
   ```

   Пути к моделям указывать не нужно, если они лежат в `data\models` после шага 2.

## Как проверить: три уровня

Каждый следующий уровень — только после того, как прошёл предыдущий.

**1. Модели по отдельности и разговор без звонка (ничего никуда не звонит):**

```powershell
wewln voice check                 # загрузка каждой модели, синтез, распознавание, ответ LLM, время
wewln voice check --save-wav check.wav   # заодно сохранить синтезированную фразу
wewln voice chat                  # текстовый диалог с моделью по сценарию тестового звонка
wewln voice simulate              # весь разговор: «собеседник» говорит синтезированным голосом
wewln voice simulate --say "Да, удобно" --say "А кто это?" --save-wav talk.wav
```

`voice simulate` печатает каждую реплику и задержки: сколько заняли распознавание, первый
ответ модели и начало озвучки.

**2. Симуляция звонка** (провайдер `mock`, никто никуда не звонит):

```powershell
wewln calls test --to +994123123456   # или --softphone
wewln calls transcript 1          # расшифровка разговора (номер звонка — из вывода)
```

**3. Софтфон на своём ПК через свой Asterisk** (бесплатно, без телефонной сети) — сначала
настройка из [ASTERISK.md](ASTERISK.md), раздел «Голосовой разговор»:

```powershell
wewln calls preflight --softphone # всё по порядку: настройки, Asterisk, модели, звук звонка
wewln calls test --softphone      # MicroSIP зазвонит, ответьте и поговорите
```

Реальный звонок на номер — только после всех проверок, с SIP-провайдером, режимом
`production` и разовым разрешением (`wewln calls permit`, см. [SECURITY.md](../SECURITY.md)).
Перед ним: `wewln calls preflight --to <номер>`.

## Как идёт разговор

- **Приветствие** (`WEWLN_VOICE_GREETING`), затем ответы модели по сценарию: для тестового
  звонка — `WEWLN_VOICE_TEST_SCRIPT`, для кампании — её «Сценарий». Приветствие по умолчанию
  сразу говорит, что звонит автоматический помощник, а модель по системной подсказке не
  выдаёт себя за человека и не выдумывает фактов, которых нет в сценарии.
- **Конец реплики** — пауза `WEWLN_VOICE_END_SILENCE_MS` (700 мс). Короткие звуки (щелчок,
  кашель) репликой не считаются, слишком длинный монолог обрезается через 15 с.
- **Ответ потоком.** Модель пишет ответ по словам, каждое законченное предложение сразу
  озвучивается, поэтому собеседник слышит начало ответа раньше, чем модель его допишет.
- **Перебивание** (`WEWLN_VOICE_BARGE_IN=true`). Если собеседник говорит поверх wewln дольше
  0,3 с, wewln замолкает и слушает. Короткое «ага» не перебивает. В расшифровке такая реплика
  отмечена как прерванная, а модель знает, что её перебили.
- **Защита от эха.** Пока wewln говорит и ещё 0,4 с после, звук с линии считается речью,
  только если он не тише голоса wewln больше чем на 20 дБ. Так эхо собственного голоса не
  перебивает разговор, а громкая речь собеседника перебивает.
- **Тишина.** Через `WEWLN_VOICE_NO_INPUT_TIMEOUT` (8 с) wewln переспрашивает «Алло? Вы меня
  слышите?», после двух раз прощается и кладёт трубку.
- **Не расслышал.** Если распознавание не сработало, wewln просит повторить; после
  повторных сбоев вежливо завершает звонок.
- **«Не звоните мне».** Модель отмечает такую просьбу, кроме того, wewln сам ищет в тексте
  фразы вроде «не звоните», «удалите мой номер». Номер реального звонка попадает в список
  «Не звонить», разговор вежливо заканчивается. В симуляции список не меняется.
- **Ограничения:** не больше `WEWLN_VOICE_MAX_TURNS` (12) реплик собеседника и
  `WEWLN_CALL_MAX_DURATION` секунд на звонок; аварийная остановка (`wewln calls stop-all`)
  завершает и разговор.
- **Сбои.** Если не загружается модель, `calls run` и `calls test` не начинают звонить. Если
  модель отказала посреди разговора, wewln говорит заранее синтезированную фразу о
  технических неполадках и кладёт трубку.

## Задержка

Измерено в Linux-песочнице с 2 ядрами CPU, без видеокарты (на обычном ПК с 4–8 ядрами
должно быть быстрее, но на Windows это **не измерялось**):

| Что | Время |
| --- | --- |
| Загрузка Vosk / Piper | 1,2 с / 3–4 с (один раз при запуске) |
| Синтез фразы длиной 4 с (Piper) | 0,6 с |
| Распознавание фразы (Vosk, 8 кГц) | 0,8–1,8 с |
| Первые слова `qwen3:0.6b` после прогрева | 0,6–2 с |
| От конца реплики до начала ответа: Vosk + Piper без LLM | 1,0–1,4 с |
| То же с `qwen3:0.6b` (`voice simulate`) | 2,9–5,5 с |

Самая медленная часть — LLM. Ускоряют: модель поменьше, видеокарта для Ollama, короткий
сценарий. При запуске wewln «прогревает» модель системной подсказкой, поэтому первый ответ
в звонке не ждёт её загрузки.

## Расшифровки и персональные данные

- Звук разговора **не записывается**. WAV сохраняют только `voice check --save-wav` и
  `voice simulate --save-wav` — это синтезированный голос, а не звонок.
- Текст реплик хранится в локальной базе SQLite, если `WEWLN_VOICE_STORE_TRANSCRIPTS=true`
  (по умолчанию), и удаляется через `WEWLN_VOICE_TRANSCRIPT_DAYS` (30) дней. Удалить сразу:
  `wewln calls transcript <id> --delete`. Не хранить совсем: `WEWLN_VOICE_STORE_TRANSCRIPTS=false`.
- В логи текст разговора не попадает — только длины, задержки и причины завершения.
- Модели работают локально. Удалённый сервер LLM, распознавания или синтеза можно указать
  только по HTTPS; обычный HTTP разрешён лишь для этого компьютера и локальной сети.
- Порт AudioSocket принимает соединения только с этого компьютера и из частных сетей
  (WSL2, LAN) и только с идентификатором звонка, который wewln выдал сам.

## Настройки

Все переменные с описаниями — в [.env.example](../.env.example), раздел «Voice engine», и в
[CONFIGURATION.md](CONFIGURATION.md). Главные:

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `WEWLN_VOICE_MODE` | `off` | `ai` — голосовой разговор на ответивший звонок |
| `WEWLN_VOICE_STT` · `_STT_MODEL` | `vosk` · пусто | движок распознавания и модель (пусто — `data\models\vosk-model-small-ru-0.22`) |
| `WEWLN_VOICE_LLM` · `_LLM_URL` · `_LLM_MODEL` | `ollama` · `http://127.0.0.1:11434` · `qwen3:4b` | диалоговая модель |
| `WEWLN_VOICE_TTS` · `_TTS_MODEL` | `piper` · пусто | синтез и голос (пусто — `data\models\ru_RU-denis-medium.onnx`) |
| `WEWLN_VOICE_GREETING` · `_GOODBYE` · `_TEST_SCRIPT` | см. `.env.example` | приветствие, прощание, сценарий тестового звонка |
| `WEWLN_VOICE_END_SILENCE_MS` · `_NO_INPUT_TIMEOUT` · `_MAX_TURNS` · `_BARGE_IN` | 700 · 8 · 12 · `true` | ход разговора |
| `WEWLN_VOICE_AUDIOSOCKET_HOST` · `_PORT` · `_ADVERTISE` | `127.0.0.1` · 9092 · пусто | где wewln принимает звук звонка и какой адрес назвать Asterisk |
| `WEWLN_VOICE_STORE_TRANSCRIPTS` · `_TRANSCRIPT_DAYS` | `true` · 30 | расшифровки |
| `WEWLN_VOICE_ALLOW_DOWNLOADS` | `false` | разрешить faster-whisper самому скачивать модели |

## Если что-то не работает

| Признак | Что сделать |
| --- | --- |
| `Vosk is not installed` / `Piper is not installed` | `pip install -e ".[voice]"` |
| `no Vosk model in …` / нет файла голоса | `wewln voice download all` или укажите путь в `WEWLN_VOICE_STT_MODEL` / `WEWLN_VOICE_TTS_MODEL` |
| `voice check`: модель LLM недоступна | запущена ли Ollama (значок в трее, `ollama list`), скачана ли модель (`ollama pull qwen3:4b`) |
| Распознаётся плохо | говорите ближе к микрофону; попробуйте faster-whisper (`WEWLN_VOICE_STT=faster-whisper`, модель `small`, нужен `WEWLN_VOICE_ALLOW_DOWNLOADS=true` для первой загрузки) |
| Ответ звучит с большой задержкой | модель меньше или видеокарта для Ollama; посмотрите задержки в `wewln voice simulate` |
| wewln перебивает сам себя или замолкает без причины | эхо на линии: проверьте гарнитуру/эхоподавление софтфона; в крайнем случае `WEWLN_VOICE_BARGE_IN=false` |
| Короткие паузы посреди разговора, в журнале `call_media_dropped_by_asterisk` | ошибка AudioSocket в Asterisk 22.5.2 (Ubuntu 26.04), wewln переподключает звук сам; если мешает — Ubuntu 24.04 ([ASTERISK.md](ASTERISK.md#требования)) |
| В звонке тишина, `calls preflight` пишет про звук звонка | сеть между Asterisk и wewln — [ASTERISK.md](ASTERISK.md), раздел «Голосовой разговор» |
